# Archive

These files are historical. Nobody maintains them. They can describe features that no longer exist, classes that were never built, retired models and old prices.

Do not use them as a guide to the current code. The current docs are listed in `docs/README.md`.

The files keep their original sub-paths. Git history is kept because the files moved with `git mv`. Relative links inside archived files can point at paths that have since moved.

What lives here:

- Finished plans, phase summaries, task completion notes and agent prompts.
- One-off audits, diagnosis reports and milestone reports.
- PRDs, proposals and design papers for features that shipped in another form or not at all.
- Copies of pages that now have one canonical page (see the PR that moved them for the mapping).
