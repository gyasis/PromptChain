The honest read: PromptChain isn't missing the harness loop — it has all 14 dimensions present (ReAct tool loop, streaming, MCP, routing, sandbox, history-distillation, persistence, mid-turn input). The gaps are depth inside dimensions, and they cluster on safety & control: LLM tool calls run ungated, there's no true turn-cancel, the sandbox isn't auto-enforced, and project docs aren't auto-loaded. Fixing ~5 of these closes most of the distance to Codex.

Gaps to close — prioritized by impact × effort

Five fixes close most of the distance. The top tier is about safety & control (the real divergence from Codex), not raw capability.
HIGHsafety & control — the genuine divergence from Codex
D6
Gate LLM-invoked tool calls with approval modes
Route every agent tool call (file_write, terminal_execute, sandbox_execute) through a policy — add Codex-style suggest / auto-edit / full-auto modes reusing the existing ApprovalScreen. Today only user !-shell is gated.
app.py agent tool loop (~3320–3429) · approval_screen.py
D7
Auto-enforce the sandbox by policy, not by LLM choice
The hardened DockerExecutor already exists — route exec/file-write tool categories through it under full-auto instead of relying on the model to pick the sandbox tool. Pairs naturally with D6.
docker_executor.py · tool registry routing
D8
True turn-cancel on Ctrl+C / Esc
Wire the key handler to Task.cancel() the running turn + call request_interrupt() — today Ctrl+C only clears the input box. Complements the turn-timeout we just shipped (timeout = backstop; cancel = user control).
app.py:626 Ctrl+C handler · agentic_step_processor.request_interrupt()

▲ Where PromptChain already beats Codex — Reliability (D13)

PromptChain now bounds every turn with a configurable timeout (PROMPTCHAIN_TURN_TIMEOUT, via asyncio.wait_for), classified retry/backoff, router fallback, and a guaranteed finally cleanup so the UI can't lock up. Codex has no documented per-turn timeout — its turn ends on completion or signal. This is the one dimension where PromptChain is genuinely more turn-resilient.
