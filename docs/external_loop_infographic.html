ExternalLoop

A deterministic external loop — the external twin of AgenticStepProcessor’s internal loop. It re-runs a step (typically a whole sequential PromptChain) over a worklist or until a condition, behind a guard that can’t run away. Any model. No tools.

Wrapping a 6-step sequential chain — the state wraps around it
# inner work: 6-step SEQUENTIAL chain (one pass / doc)
def make_distill_chain():
  return PromptChain(
    models=["openai/gpt-4o-mini"]*5,  # 5 string steps
    instructions=[
      "Extract key points …{input}",   # 1
      "Group into 2-4 themes …{input}", # 2
      "Order by importance …{input}",   # 3
      "Draft a summary …{input}",       # 4
      "Tighten to TWO sentences …{input}",# 5
      lambda two: json.dumps({...}),     # 6 fn
    ])

# outer loop: ExternalLoop threads STATE
async def step(it, st):
  if not st["queue"]: return False
  doc = st["queue"].pop(0)
  out = await make_distill_chain()\
          .process_prompt_async(doc)
  st["results"].append(json.loads(out))
  return bool(st["queue"])

await ExternalLoop(max_iters=50,
       max_seconds=120).run(step, state)
