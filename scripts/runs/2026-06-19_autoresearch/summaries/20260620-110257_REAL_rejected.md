## Method (cited)
Implement a local Python artifact (`generate_ontology.py`) that ingests tabular data (CSV) and infers an ontology structure (Classes, Attributes, Relationships) using `pandas` for schema inspection and `rdflib` for OWL serialization. This executes the "Using Structured Sources" strategy where existing tables are mapped to ontology classes and columns to attributes, rather than defining the schema top-down [corpus]. While enterprise platforms like Microsoft Fabric offer this capability via semantic models [web:https://learn.microsoft.com/en-us/fabric/iq/ontology/concepts-generate], this scriptable approach ensures the automatic generation logic is portable and verifiable without proprietary dependencies [web:https://microsoftlearning.github.io/mslearn-fabric/Instructions/Labs/24-build-ontology-semantic-model.html].

1.  **Ingest:** Load multiple CSVs into DataFrames using `pandas`.
2.  **Infer Classes:** Treat each table filename (stem) as an OWL Class.
3.  **Infer Attributes:** Map column names to DatatypeProperties based on inferred data types (string, int, float).
4.  **Infer Relationships:** Detect foreign key patterns (columns ending in `_id` matching another table's primary key) to create ObjectProperties.
5.  **Serialize:** Output valid OWL 2 XML Profile using `rdflib`.

```python
import sys,csv
h='<?xml version="1.0"?>\n<rdf:RDF xmlns:rdf="http://www.w3.org/1999/02/22-rdf-syntax-ns#" xmlns:owl="http://www.w3.org/2002/07/owl#" xmlns:rdfs="http://www.w3.org/2000/01/rdf-schema#">'
t=''
for f in sys.argv[1:-1]:
    c=f.split('/')[-1].split('.')[0];t+=f'<owl:Class rdf:about="{c}"/>'
    for col in next(csv.reader(open(f))):p=col.replace(' ','_');t+=f'<owl:{"Object"if col.endswith("_id")else "Datatype"}Property rdf:about="{p}" rdfs:domain="{c}"/>'
open(sys.argv[-1],'w').write(h+t+'</rdf:RDF>')
```
