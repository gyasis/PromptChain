## Method (cited)
Execute the conversion using DuckDB's `COPY` statement with `read_csv_auto` for schema inference and `PARTITION_BY` for output organization. DuckDB executes fully in-process with vectorized execution, pushing operations to disk rather than RAM to handle large datasets without overflow [corpus]. Benchmarks confirm DuckDB maintains low memory consumption during CSV-to-Parquet conversion compared to Pandas/Polars while handling automatic type detection [web:https://medium.com/@mariusz_kujawski/converting-csv-files-to-parquet-with-polars-pandas-dask-and-dackdb-52a77378349d].

**Implementation Pattern:**
```sql
COPY (
  SELECT * FROM read_csv_auto('input.csv', ALL_VARCHAR=false)
) TO 'output_dir' (
  FORMAT PARQUET,
  COMPRESSION 'zstd',
  PARTITION_BY partition_column
);
```
This approach ensures columnar compression, portable outputs compatible with Spark/Pandas/Snowflake, and streaming ingestion that avoids loading the full CSV into memory [corpus].
