## Method (cited)  

The solution follows the classic text‑analysis pipeline that is widely documented in Python tutorials and stack‑overflow answers:

1. **Tokenisation** – Use a regular expression `\b\w+\b` to extract alphabetic‑numeric tokens, ignoring punctuation.  
2. **Normalisation** – Convert every token to lower‑case so that “Word” and “word” are counted together.  
3. **Counting** – Feed the token list into `collections.Counter`, which builds a hash‑map of *word → frequency* in O(n) time.  
4. **Top‑5 selection** – Call `Counter.most_common(5)` to retrieve the five most frequent `(word, count)` pairs in descending order.  
5. **Printing** – Iterate over the returned list and print each tuple exactly as `(<word>, <count>)`.

These steps are directly taken from the pattern described in the Python “text analysis” literature (e.g., the official `collections` documentation and numerous code‑samples on word‑frequency counting [corpus]/[web:https://wordcounter.net/]).

import re
from collections import Counter

def top_five(paragraph: str):
    # 1️⃣ tokenise + normalise
    tokens = re.findall(r"\b\w+\b", paragraph.lower())
    # 2️⃣ count
