## Method (cited)

The solution follows a classic text‑processing pipeline that is well‑documented in the Python standard library:

1. **Tokenisation** – Use a regular‑expression `r'\b[a-zA-Z]+\b'` to extract alphabetic tokens only, thereby discarding punctuation and numbers.  
2. **Normalisation** – Convert every token to lower‑case so that “Word” and “word” are treated as the same entry.  
3. **Counting** – Feed the resulting list of words to `collections.Counter`, which builds a hash‑map of word → frequency in O(N) time.  
4. **Ranking** – Call `Counter.most_common(5)` to obtain the five highest‑frequency items, already sorted by descending count and then by first appearance order (Python’s `Counter` guarantees a stable order for ties).  
5. **Presentation** – Print each `(word, count)` tuple on its own line (or as a single list, depending on the caller’s preference).

This approach is the most reliable for the given brief because it relies solely on battle‑tested, built‑in modules (`re` and `collections`) and avoids external dependencies or heavy NLP pipelines. import re
from collections import Counter

def top_five(text: str):
    # 1️⃣ Tokenise & normalise
    words = re.findall(r'\b[a-zA-Z]+\b', text.lower())
    # 2️⃣ Count frequencies
    return Counter(words).most_common(5)
