## Method (cited)

We will implement a fixed‑capacity **Least‑Recently‑Used (LRU) cache** with the classic *hash‑map + doubly‑linked list* design so that both `get(key)` and `put(key, value)` run in **O(1)** time.

* **Hash map (`dict`)** – maps a key to its node in the linked list for constant‑time lookup.  
* **Doubly‑linked list** – stores nodes in recency order, **head = most recent**, **tail = least recent**.  

Operations  

| Operation | Steps (O(1)) |
|-----------|--------------|
| `get(k)`  | 1. Look up `k` in the dict. <br>2. If missing → return `None`. <br>3. Move the node to the head of the list (unlink → re‑link). <br>4. Return its value. |
| `put(k, v)`| 1. If `k` already exists → update value, move node to head. <br>2. Else create a new node, insert at head, add to dict. <br>3. If size > capacity → evict tail node (remove from list & dict). |

The algorithm follows the description in Yomguithereal’s LRU guide [web:https://yomguithereal.github.io/posts/lru-cache/] and is also the solution pattern used in LeetCode 146.

Implementation details  

* Node class with `key`, `value`, `prev`, `next`.  
* Helper methods: `_add_to_head(node)`, `_remove(node)`, `_pop_tail()`.  
* Public API: `__init__(capacity)`, `get(key)`, `put(key, value)`, optional `__len__` for testing.

# lru_cache.py
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity):
        self.cap, self.d = capacity, OrderedDict()
    def get(self, k):
        if k not in self.d: return None
        v = self.d.pop(k)
        self.d[k] = v
        return v
    def put(self, k, v):
        if k in self.d: self.d.pop(k)
        self.d[k] = v
        if len(self.d) > self.cap:
            self.d.popitem(last=False)
