```python
def dedupe_keep_last(records, id_key="id"):
    """
    Remove duplicate dictionaries from ``records`` while **keeping the last
    occurrence** of each ``id_key`` value.

    The algorithm walks the list *backwards* and stores each element in a
    temporary dict keyed by ``id_key``. Because we encounter the *last*
    occurrence first, later (earlier‑in‑the‑original) duplicates are overwritten.
    Finally we return the values in the order of their original appearance
    (i.e. the order of the last occurrences).

    Time   : O(n)
    Memory : O(k) where k = number of distinct ids

    References
    ----------
    - “Remove duplicate dictionaries from a list. Converts each dict to a
      frozenset for comparison.” – OneUptime blog, *keep_last_occurrence* example
      (https://oneuptime.com/blog/post/2026-01-25-remove-duplicates-from-list-python/view)
    - “Working with lists of dictionaries … To keep the last occurrence of duplicates,
      remove …” – PythonTutorials.net (https://www.pythontutorials.net/blog/python-manipulation-with-a-list-of-dictionaries/)
    """
    temp = {}
    # iterate reversed so the *last* occurrence is seen first
    for rec in reversed(records):
        if id_key not in rec:
            raise KeyError(f"Record {rec!r} missing required key '{id_key}'")
        temp[rec[id_key]] = rec
    # values are in reverse‑order of first appearance; reverse again to restore original order
    return list(reversed(list(temp.values())))
```

### Why this works
1. **Reverse iteration** guarantees that when a duplicate id is encountered,
   the *later* (i.e., the one that should be kept) is stored first.
2. Assigning to `temp[rec[id_key]]` overwrites any earlier entry for the same id,
   ensuring the dict finally holds the last record.
3. Converting `temp.values()` to a list and reversing restores the order of
   the surviving records to match their *last* occurrence positions in the
   original list.
