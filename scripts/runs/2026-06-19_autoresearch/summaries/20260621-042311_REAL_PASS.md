## Chosen Approach  
The most reliable solution is to (1) index the edge list into a `{parent: [children]}` map, (2) recursively walk from the identified root(s) to assemble a nested dictionary where each key is a node and its value is the subtree built from its children, and (3) validate the result by (a) confirming that every node appears exactly once (to detect duplicates or cycles) and (b) using a structural‑assertion helper such as `tree.assert_same_structure` to guarantee that the generated hierarchy matches the original edge relationships. ## Method (cited)

1. **Index edges** – Build a mapping `children_of[parent] = [child, …]` from the flat list of `(parent, child)` tuples.  
   *Citation*: Xah Lee’s “Construct a Tree Given Its Edges” demonstrates this first‑pass indexing step【web】.  

2. **Detect roots** – A node that never appears as a child is a root. If more than one root is found the function will return a dictionary with each root at top level (i.e., a forest).  

3. **Recursive assembly** – Starting from each root, recursively create a nested dictionary:  

   ```python
   def _build(node):
       return {node: {c: _build(c) for c in children_of.get(node, [])}}
   ```  

   The recursion stops when a node has no entry in `children_of`.  

4. **Cycle / duplicate guard** – While recursing keep a `visited` set; if we encounter a node already in `visited` we raise `ValueError("cycle detected")`. This guarantees every node appears exactly once in the final structure.  

5. **Verification** – After construction we run two cheap checks:  

   * **Cardinality check** – `len(all_nodes)` must equal `len(set(all_nodes))`.  
   * **Structure check** – A helper `assert_same_structure` (inspired by the `tree` library) walks the produced dict and the original edge list in parallel, asserting that every parent‑child relationship is present and no extra edges exist.  

   ```python
   def assert_same_structure(tree, edges):
       edge_set = set(edges)
       def _walk(node, subtree):
           for child in subtree:
               assert (node, child) in edge_set, f"Missing edge {node}->{child}"
               _walk(child, subtree[child])
       for root in tree:
           _walk(root, tree[root])
       # ensure no stray edges
       visited = set()
       def _collect(node, sub):
           visited.add(node)
           for c in sub:
               _collect(c, sub[c])
       for r in tree:
           _collect(r, tree[r])
       assert visited == {p for p, _ in edges} | {c for _, c in edges}
   ```

6. **Export** – The public API exposed to callers is a single function `build_tree(edges: List[Tuple[str, str]]) -> Dict`. It returns the nested dict (or dict‑of‑roots for a forest) and raises clear exception

from collections import defaultdict
def build_tree(edges):
    if not edges: return {}
    children=defaultdict(list); childs=set(); nodes=set()
    for p,c in edges:
        children[p].append(c); childs.add(c); nodes.update((p,c))
    roots=[n for n in nodes if n not in childs]
    if not roots: raise ValueError("cycle")
    visited=set()
    def rec(n):
        if n in visited: raise ValueError("cycle")
        visited.add(n)
        return {c:rec(c) for c in children.get(n,[])}
    forest={}
    for r in roots: forest.update({r:rec(r)})
    edge_set=set(edges)
    def walk(p,sub):
        for c,s in sub.items():
            assert (p,c) in edge_set
            walk(c,s)
    for r,s in forest.items(): walk(r,s)
    assert visited==nodes
    return forest
