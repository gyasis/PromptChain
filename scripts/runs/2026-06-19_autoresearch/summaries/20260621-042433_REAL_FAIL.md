## Method (cited)

1. **Parse ISO‑8601 strings** – Convert each incoming string to a native timestamp using DuckDB’s `to_timestamp()` (or Python’s `datetime.fromisoformat`).  
2. **Create non‑overlapping hourly buckets** – Apply `date_trunc('hour', ts)` (DuckDB) or `ts.replace(minute=0, second=0, microsecond=0)` (Python) **immediately after parsing**. Doing the truncation before any `GROUP BY` keeps the operation vectorised and avoids per‑row Python overhead.  
3. **Aggregate** – `COUNT(*)` per bucket gives the hourly event histogram.

```python
from datetime import datetime
from collections import Counter

def bucket_iso(ts):
    c = Counter()
    for s in ts:
        # ISO‑8601 Z → UTC offset for fromisoformat
        d = datetime.fromisoformat(s.replace('Z', '+00:00')).replace(minute=0, second=0, microsecond=0)
        c[d.isoformat()] += 1
    return dict(c)
```
