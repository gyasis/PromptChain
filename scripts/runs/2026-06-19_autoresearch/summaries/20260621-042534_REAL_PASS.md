## Method (cited)

We will implement a deterministic, linear‑time validator that:

1. Takes a list `dicts` of dictionaries.
2. Uses the key‑set of the **first** dictionary as the reference `ref_keys`.
3. Iterates over the remaining dictionaries, computes `cur_keys = set(d)` and:
   * `missing = ref_keys - cur_keys`
   * `extra   = cur_keys - ref_keys`
4. For every dictionary where `missing` or `extra` is non‑empty, records a mismatch entry  
   ```python
   {
       "index": i,                # position in the original list
       "missing_keys": sorted(missing),
       "extra_keys":   sorted(extra)
   }
   ```
5. Returns a list of all mismatch entries; an empty list means **all dicts share the exact same keys**.

The algorithm is O(N·K) where *N* is the number of dictionaries and *K* the average number of keys, matching the canonical solution discussed on StackOverflow [1][2].

```python
def validate_dict_keys(dicts):
    """
    Validate that all dictionaries in *dicts* have identical key sets.

    Parameters
    ----------
    dicts : list[dict]
        List of dictionaries to validate. Must contain at least one element.

    Returns
    -------
    list[dict]
        A list of mismatch reports. Each report is a dict with keys
        ``index``, ``missing_keys`` and ``extra_keys``. Empty list → success.
    """
    if not dicts:                     # nothing to validate
        return []

    ref_keys = set(dicts[0])
    mismatches = []

    for i, d in enumerate(dicts[1:], start=1):
        cur_keys = set(d)
        missing = ref_keys - cur_keys
        extra   = cur_keys - ref_keys
        if missing or extra:
            mismatches.append({
                "index": i,
                "missing_keys": sorted(missing),
                "extra_keys":   sorted(extra)
            })
    return mismatches
```
