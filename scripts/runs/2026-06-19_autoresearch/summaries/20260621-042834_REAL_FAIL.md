## Chosen Approach  
Implement Welford’s one‑pass algorithm by maintaining three state variables – the number of samples *n*, the current mean *μ*, and the sum of squared deviations *M2*. For each new value *x* update them as:  

```
n   ← n + 1
δ   ← x – μ
μ   ← μ + δ / n
δ2  ← x – μ          // new mean
M2  ← M2 + δ * δ2
```

After processing the list, the variance is `M2 / (n‑1)` for the unbiased estimator (or `M2 / n` for the population variance). ## Method (cited)

We will implement **Welford’s one‑pass algorithm** for online computation of the mean µ and variance σ² over an arbitrary iterable of numbers.

**Algorithm sketch**

```
n   ← 0                # sample count
μ   ← 0.0              # running mean
M2  ← 0.0              # sum of squared deviations

for x in data:
    n   ← n + 1
    δ   ← x - μ
    μ   ← μ + δ / n
    δ2  ← x - μ            # deviation from new mean
    M2  ← M2 + δ * δ2
```

After the loop:

* **Population variance**  σ² = M2 / n  (when n > 0)  
* **Sample (unbiased) variance** s² = M2 / (n‑1) (when n > 1)

The implementation will expose a single public function:

# welford.py
from typing import Iterable, Tuple

def welford_mean_variance(
    vals: Iterable[float],
    *,
    population: bool = True,
    ddof: int | None = None,
) -> Tuple[float, float]:
    n = 0
    mean = M2 = 0.0
    for x in vals:
        n += 1
        d = x - mean
        mean += d / n
        M2 += d * (x - mean)
    if n == 0:
        raise ValueError("empty input")
    if ddof is not None:
        div = n - ddof
    else:
        div = n if population else n - 1
    if div <= 0:
        raise ValueError("invalid divisor")
    return mean, M2 / div
```
