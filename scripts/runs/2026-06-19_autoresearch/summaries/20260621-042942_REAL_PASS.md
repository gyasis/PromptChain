## Method (cited)

We will implement the classic *two‑pointer merge* algorithm, the merge step of merge‑sort:

1. Initialise two indices `i` and `j` at 0 for the two input lists `A` and `B`.
2. While both indices are within their respective list lengths:  
   * Compare `A[i]` and `B[j]`.  
   * Append the smaller value to a new result list `R`.  
   * Increment the index (`i` or `j`) of the list whose element was taken.  
3. When one list is exhausted, extend `R` with the remaining slice of the other list.
4. Verify that `R` is sorted by a single linear scan checking `R[k] ≤ R[k+1]` for all valid `k`.  
   * If any violation is found raise an `AssertionError`.

The algorithm runs in **O(n + m)** time and **O(n + m)** auxiliary space (the output list), and never invokes Python’s built‑in `sorted()` or `list.sort()` functions, satisfying the “no sort()” requirement.  

The approach is directly taken from common interview/educational material on merging sorted sequences [web:https://stackoverflow.com/questions/77312708/how-to-merge-and-sort-lists-of-different-lengths-without-sort-functions] and the Python exercise repository [web:https://inventwithpython.com/pythongently/exercise40/].
