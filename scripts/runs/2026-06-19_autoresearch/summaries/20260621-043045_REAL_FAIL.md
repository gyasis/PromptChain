## Method (cited)  
The classic stack‑based algorithm is the most reliable way to decide whether a string’s brackets are balanced.  

1. Initialise an empty list `stack`.  
2. Iterate over each character `ch` in the input string.  
   * If `ch` is an opening bracket – one of `(`, `[`, `{` – push the corresponding closing bracket (`)`, `]`, `}`) onto `stack`.  
   * If `ch` is a closing bracket – one of `)`, `]`, `}` – the string is invalid unless `stack` is non‑empty **and** `stack.pop()` equals `ch`.  
3. After the loop, the string is valid iff `stack` is empty.  

This algorithm automatically handles nesting, mixed‑type brackets, and early premature closing. The approach is described in many tutorials, e.g. in a YouTube walkthrough of a stack solution [web:https://www.youtube.com/watch?v=GC4RVjgoTNY] and a Python‑centric discussion on balanced parentheses [web:https://software.codidact.com/posts/282231/290580].

```python
def is_balanced(s: str) -> bool:
    """Return True if *s* contains a correctly balanced sequence of (), [], {}."""
    pairs = {')': '(', ']': '[', '}': '{'}
    stack: list[str] = []
    for ch in s:
        if ch in pairs.values():               # opening
            stack.append(ch)
        elif ch in pairs:                      # closing
            if not stack or stack.pop() != pairs[ch]:
                return False
        # non‑bracket characters are ignored
    return not stack
```
