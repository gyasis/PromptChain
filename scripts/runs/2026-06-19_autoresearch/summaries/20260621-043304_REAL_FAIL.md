## Method (cited)  
We will implement a **streaming CSV → NDJSON converter** in pure Python, using only the standard library (`csv`, `json`, and `io`).  

1. **Read** the input file with `open(..., newline='')` and feed it to `csv.DictReader`. `DictReader` parses one CSV record at a time, yielding a `dict` that maps column names to string values.  
2. **Transform** each `dict` into a JSON string with `json.dumps(record, ensure_ascii=False)`. The result is a single‑line JSON object.  
3. **Write** the JSON string followed by a newline (`'\n'`) to the output file opened in text mode.  
4. Because the reader and writer operate row‑by‑row, memory usage stays **O(1)** regardless of input size.  

This design follows the streaming principles described in the JSON‑Lines literature【corpus:memory_lane_v4】 and mirrors the pattern used by Node.js streaming CSV parsers【web:csv-parser】.  

```python
#!/usr/bin/env python3
import csv
import json
import sys
from pathlib import Path

def csv_to_ndjson(csv_path: Path, ndjson_path: Path, *, encoding: str = "utf-8") -> None:
    """Convert CSV → newline‑delimited JSON (NDJSON) using a constant‑memory stream."""
    with csv_path.open("r", newline="", encoding=encoding) as src, \
         ndjson_path.open("w", encoding=encoding) as dst:
        reader = csv.DictReader(src)
        for row in reader:
            dst.write(json.dumps(row, ensure_ascii=False) + "\n")

if __name__ == "__main__":
    if len(sys.argv) != 3:
        prog = Path(sys.argv[0]).name
        sys.stderr.write(f"Usage: {prog} <input.csv> <output.ndjson>\\n")
        sys.exit(2)
    csv_to_ndjson(Path(sys.argv[1]), Path(sys.argv[2]))
```

The script can be invoked as  

```bash
python csv_to_ndjson.py data.csv data.ndjson
```
