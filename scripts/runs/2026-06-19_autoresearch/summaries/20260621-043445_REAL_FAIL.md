## Method (cited)  
We will implement an **in‑memory token‑bucket rate limiter** in Python. The algorithm follows the classic definition:

1. **State** – each bucket stores:  
   * `capacity` – maximum tokens the bucket can hold.  
   * `rate` – token addition rate (tokens per second).  
   * `tokens` – current token count (float).  
   * `last_refill` – monotonic timestamp of the last refill.  

2. **Refill** – on every request we compute the elapsed time since `last_refill`, add `elapsed × rate` tokens (capped at `capacity`), and update `last_refill`.  

3. **Consume** – if after refill `tokens ≥ 1` we decrement by 1 and **allow** the request; otherwise we **reject**.  

The implementation will be pure Python with no external dependencies, making it easy to embed in any service (FastAPI, Flask, CLI, etc.).

import time
class TokenBucket:
    __slots__=('c','r','t','l')
    def __init__(self,c,r,now=None):
        self.c=self.t=float(c);self.r=float(r);self.l=now if now is not None else time.monotonic()
    def _ref(self,now):
        e=now-self.l
        if e>0:self.t=min(self.c,self.t+e*self.r);self.l=now
    def allow(self,now=None):
        now=time.monotonic() if now is None else now
        self._ref(now)
        if self.t>=1:self.t-=1;return True
        return False

from ratelimit import TokenBucket
N=5
