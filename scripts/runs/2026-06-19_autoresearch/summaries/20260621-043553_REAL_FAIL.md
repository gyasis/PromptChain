## Method (cited)  
1. **Data structure design** – Create a `TrieNode` class.  
   *Each node stores a fixed‑size list of 26 child pointers (one per lowercase English letter) and a boolean `is_end` flag.*  
   This is the canonical representation described in the “Trie” section of the Medium article on prefix trees【1】 and in typical LeetCode solutions【2】.  

2. **Trie class API** – Implement three public methods:  
   * `insert(word: str) -> None` – walk the tree character‑by‑character, creating missing child nodes, and set `is_end` on the terminal node.  
   * `search(word: str) -> bool` – identical walk but returns `True` only if the terminal node exists **and** its `is_end` flag is set.  
   * `startsWith(prefix: str) -> bool` – walk the tree for the prefix; return `True` if the walk never hits a missing child (regardless of `is_end`).  

3. **Complexity guarantees** – Each operation runs in **O(L)** time where *L* is the length of the input string, and uses **O(N·L)** space for *N* inserted words (shared prefixes are stored once) – the standard guarantees for a prefix trie【1】.  

4. **Verification strategy** – After implementation, run a tiny self‑contained test suite that:  
   * Inserts a known list of words (`["ace","ant","cat","pen","pet"]`).  
   * Checks that `search` returns `True` for each inserted word and `False` for a non‑member (`"dog"`).  
   * Checks that `startsWith` returns `True` for prefixes that exist (`"pe"`, `"a"`), and `False` for nonexistent prefixes (`"pa"`, `"z"`).

# trie.py
class Trie:
    def __init__(self):
        self.root = {}

    def insert(self, w):
        node = self.root
        for c in w:
            node = node.setdefault(c, {})
        node['_'] = 1

    def search(self, w):
        node = self.root
        for c in w:
            if c not in node:
                return False
            node = node[c]
        return node.get('_', False)

    def startsWith(self, p):
        node = self.root
        for c in p:
            if c not in node:
                return False
            node = node[c]
        return True
