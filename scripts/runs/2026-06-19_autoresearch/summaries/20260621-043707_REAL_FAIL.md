## Method (cited)  

1. **Read the CSV with pandas** – `pandas.read_csv` performs automatic type inference for each column (integer, float, datetime, object) using the same heuristics described in the pandas documentation [https://pandas.pydata.org/pandas-docs/stable/reference/api/pandas.read_csv.html] and in the blog “How pandas infers data types when parsing CSV files” [https://rushter.com/blog/pandas-data-type-inference/].  

2. **Detect the final dtype** for every column:  

   ```python
   import pandas as pd
   import sys
   from pathlib import Path

   def infer_schema(csv_path: Path, **read_kwargs) -> dict[str, str]:
       # 1) Load CSV, disabling the low‑memory chunked inference for small files
       df = pd.read_csv(csv_path, low_memory=False, **read_kwargs)

       schema = {}
       for col, dtype in df.dtypes.items():
           # pandas may report "object" for mixed or string columns
           if pd.api.types.is_integer_dtype(dtype):
               schema[col] = "int"
           elif pd.api.types.is_float_dtype(dtype):
               schema[col] = "float"
           elif pd.api.types.is_datetime64_any_dtype(dtype):
               schema[col] = "date"
           else:
               schema[col] = "str"
       return schema
   ```

3. **Emit a human‑readable report** (JSON or plain‑text). The implementation below prints a JSON‑object to `stdout`, which is easy to consume by downstream tools.

   ```python
   import json

   if __name__ == "__main__":
       csv_file = Path(sys.argv[1])
       # let pandas try to parse dates automatically (it will succeed only if the column looks like a date)
       schema = infer_schema(csv_file, infer_datetime_format=True)
       json.dump(schema, sys.stdout, indent=2)
   ```

   * Empty columns are reported as `"str"` because pandas treats them as object with all‑null values.

#!/usr/bin/env python3
import sys, json, pandas as pd
p = pd.read_csv(sys.argv[1], low_memory=False)
for c in p.select_dtypes('object'):
    t = pd.to_datetime(p[c], errors='ignore')
    if t.dtype.kind == 'M': p[c] = t
m = {'int':'int','float':'float','datetime64[ns]':'date'}
print(json.dumps({c: m.get(str(d), 'str') for c, d in p.dtypes.items()}, indent=2))
