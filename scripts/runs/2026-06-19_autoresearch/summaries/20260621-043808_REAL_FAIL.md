## Method (cited)

We will implement **Algorithm R** (the classic reservoir sampling algorithm) for drawing a uniform random sample of size `k` from a potentially unbounded stream. The algorithm proceeds in two phases:

1. **Initialization** – fill a list `reservoir` with the first `k` items from the stream.  
2. **Replacement** – for each subsequent item with 1‑based index `i` (i > k):  
   * draw a random integer `j` uniformly from `[0, i‑1]` (Python: `random.randrange(i)`);  
   * if `j < k`, replace `reservoir[j]` with the current item.  

This guarantees that after processing the *i*‑th element, each of the first *i* items is present in the reservoir with probability `k / i`, yielding a uniform sample of exactly `k` elements (or fewer if the stream is shorter) 【web:https://en.wikipedia.org/wiki/Reservoir_sampling】.

import random, sys
from typing import Iterable, List, Any

def reservoir_sample(stream: Iterable[Any], k: int) -> List[Any]:
    if k < 0: raise ValueError
    res = []
    for i, x in enumerate(stream, 1):
        if i <= k:
            res.append(x)
        else:
            j = random.randrange(i)
            if j < k:
                res[j] = x
    return res
