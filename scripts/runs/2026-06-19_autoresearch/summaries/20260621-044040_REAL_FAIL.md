## Method (cited)  

1. **Stream the CSV** – Open the target CSV with `utf‑8` encoding and iterate line‑by‑line using Python’s built‑in `csv` module.  
2. **Normalize each row** – Strip surrounding whitespace from each field and join the fields with a constant delimiter (e.g. a comma). This guarantees that semantically identical rows obtain the same representation regardless of incidental spacing.  
3. **Deterministic hashing** – Compute a fast, cryptographically‑stable hash of the normalized row string.  
   ```python
   import hashlib
   row_hash = hashlib.sha256(normalised.encode('utf-8')).hexdigest()
   ```
   SHA‑256 is chosen because it is readily available in the stdlib, has negligible collision risk for the data sizes we target, and works on any length of input【web:https://www.w3reference.com/blog/remove-duplicate-rows-from-a-large-file-in-python/】.  
4. **Count occurrences** – Store the hash in an in‑memory dictionary `hash_counts` where the value is the number of times the hash has been seen.  
5. **Compute duplicate ratio** – After the whole file is processed:  

   * `total_rows` = number of rows read (including duplicates)  
   * `unique_rows` = `len(hash_counts)`  

   The duplicate ratio is  

   \[
   \text{duplicate\_ratio} = \frac{\text{total\_rows} - \text{unique\_rows}}{\text{total\_rows}}
   \]

   This matches the definition used in “row‑hashing + fuzzy matching” tools where the ratio reflects the fraction of rows that are exact copies of another row【web:https://github.com/dshradha/Data-Shadow-Slayer】.  

6. **Report** – Print the ratio as a floating‑point number with three decimals (or JSON if downstream automation is required).  

The algorithm is O(N) time, O(U) memory where *U* is the number of distinct rows, and requires only the Python standard library.

# impl.py
import sys, csv, hashlib
s, n = set(), 0
for r in csv.reader(open(sys.argv[1], encoding="utf-8", errors="replace")):
    if not r: continue
    n += 1
    s.add(hashlib.sha256(",".join(map(str.strip, r)).encode()).hexdigest())
print((n - len(s)) / n if n else 0)
