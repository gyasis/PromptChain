## Chosen Approach  
Use a lazy “two‑way merge” that keeps only the current record from each sorted input stream, repeatedly compares their keys, emits the smaller record, and pulls the next record from that stream.  A min‑heap (or simple two‑element comparison for just two streams) guarantees O(log k) (here k = 2) per output and lets you verify that each emitted key is not less than the previous one, catching any ordering violations on the fly. ## Method (cited)

We will implement a **lazy two‑way merge** that never holds more than one record from each input.  
The algorithm works as follows:

1. **Open the two input streams** as iterators that yield dictionaries (or tuples) sorted by a common key `k`.  
2. **Prime the merge** by reading the first element from each iterator (`a_cur`, `b_cur`).  
3. **Loop** while at least one current element is not `None`  
   * If one side is exhausted, emit the remaining element(s) from the other side.  
   * Otherwise compare `a_cur[k]` and `b_cur[k]`.  
   * Emit the smaller (or equal) element, then advance the iterator that supplied it.  
4. **Ordering check** – keep the last emitted key `prev_k`. After emitting a new record, assert `new_k >= prev_k`. If the assertion fails, raise `ValueError` with a clear message; this guarantees that the merge itself detects any disorder in the inputs.  

The algorithm is identical to the one described in the open‑source **`sorted-merge-stream`** Node.js library 【github:cshum/sorted-merge-stream】 and the classic heap‑based stream‑merge description on **The Algo Blog** 【web:http://the-algo-blog.blogspot.com/2008/11/merging-sorted-streams.html】, specialised here to the `k = 2` case where a full heap is unnecessary.

def merge_sorted(stream_a, stream_b, key):
    a, b = iter(stream_a), iter(stream_b)
    A = next(a, None)
    B = next(b, None)
    prev = None
    while A or B:
        if B is None or (A is not None and A[key] <= B[key]):
            cur, A = A, next(a, None)
        else:
            cur, B = B, next(b, None)
        k = cur[key]
        if prev is not None and k < prev:
            raise ValueError("ordering violation")
        prev = k
        yield cur
