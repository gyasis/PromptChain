## Chosen Approach  
Maintain an array of bin counters sized for the desired fixed‑width interval \([{\rm min}, {\rm max})\) and, for each incoming value \(x\), compute its bin index with integer arithmetic  
\(i = \big\lfloor (x - {\rm min}) / w \big\rfloor\) where \(w\) is the bin width, then increment `counts[i]` [web:https://numpy.org/doc/stable/reference/generated/numpy.histogram.html]. After the stream ends, verify correctness simply by checking that \(\sum_i \text{counts}[i] = N\) [web:https://www.geeksforgeeks.org/numpy/binning-data-in-python-with-scipy-numpy/]. ## Method (cited)  
We will implement a streaming, fixed‑width‑bin histogram in pure Python (optionally using **NumPy** for convenience).  

1. **Determine bin edges**  
   * Input parameters: `min_val`, `max_val`, `bin_width`.  
   * Number of bins `B = ceil((max_val - min_val) / bin_width)`.  
   * Edge of bin `i` (0‑based) is `[min_val + i·bin_width,  min_val + (i+1)·bin_width)`.  

2. **Streaming update**  
   For each incoming value `x` in the numeric stream:  

   ```python
   idx = int((x - min_val) // bin_width)   # floor division gives the correct bin
   if 0 <= idx < B:
       counts[idx] += 1
   else:
       # values outside the specified range are ignored or could be
       # placed in under‑/overflow bins (not required for the core task)
   ```  

   This mirrors the integer‑arithmetic approach described in NumPy’s `histogram` implementation [https://numpy.org/doc/stable/reference/generated/numpy.histogram.html] and TensorFlow’s `histogram_fixed_width_bins` primitive [https://www.slingacademy.com/article/tensorflow-histogram-fixed-width-bins-binning-values-for-histograms-in-tensorflow/].  

3. **Verification**  
   After processing the whole stream we compute the total count  

   ```python
   total = sum(counts)
   assert total == N, f"Histogram counts {total} != expected N={N}"
   ```  

   The assertion directly follows the verification step suggested by GfG [https://www.geeksforgeeks.org/numpy/binning-data-in-python-with-scipy-numpy/].  

4. **API**

                             min_val: float,

       """Return a list of bin counts for the stream; the sum of counts equals len(stream)."""
