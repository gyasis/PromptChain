## Method (cited)  
Implement a deterministic variant of **Kahn’s algorithm** [1] for topological sorting. The algorithm proceeds as follows:

1. **Build indegree map** for every node from the supplied `(node, deps)` pairs.  
2. **Initialize a queue** with all nodes whose indegree is 0, preserving the original input order.  
   * To guarantee stability, use a `collections.deque` populated by iterating the original list once; when a node’s indegree drops to 0 later, append it to the deque (preserving the moment it became eligible).  
3. **Iteratively pop** the left‑most node from the deque, append it to the output ordering, and decrement the indegree of its dependents.  
   * If a dependent’s indegree becomes 0, enqueue it as described above.  
4. Detect cycles: if the output size < number of distinct nodes, raise `ValueError`.  

After producing the ordering, **verify** it by scanning the list and ensuring that each node appears after all of its declared dependencies. This verification step is O(V + E) and serves as a sanity check before returning the result.

from collections import deque,defaultdict

def stable_toposort(pairs):
    """stable topological sort of (node, deps) preserving input order."""
    indeg=defaultdict(int); g=defaultdict(list); order=[n for n,_ in pairs]
    for n,ds in pairs:
        for d in ds: g[d].append(n); indeg[n]+=1
    q=deque([n for n in order if indeg[n]==0])
    res=[]
    while q:
        n=q.popleft(); res.append(n)
        for m in g[n]:
            indeg[m]-=1
            if indeg[m]==0: q.append(m)
    if len(res)!=len(order): raise ValueError("graph contains a cycle")
    pos={n:i for i,n in enumerate(res)}
    for n,ds in pairs:
        for d in ds:
            if pos[d]>pos[n]: raise AssertionError
    return res
