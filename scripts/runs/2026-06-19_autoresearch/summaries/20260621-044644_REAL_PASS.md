## Chosen Approach  
Maintain a **Count‑Min Sketch (CMS)** to ingest each incoming item in O(1) space‑efficient time, and keep a **size‑K min‑heap** (or a deterministic Space‑Saving table) of the current top‑K candidates. After each update, use the CMS to obtain an over‑estimate of an item’s frequency; if this estimate exceeds the smallest count in the heap, replace that entry with the new item and its estimate, thus guaranteeing that the heap always contains the K items with the highest estimated counts. Periodically (or on demand) output the heap contents as the reported top‑K heavy hitters. This hybrid CMS‑plus‑heap design balances sub‑linear memory, constant‑time updates, and accurate top‑K retrieval, as recommended for streaming heavy‑hitter systems [web:https://robinali34.github.io/blog_system_design/2025/11/14/design-top-k-heavy-hitter/].

## Method (cited)  

We will implement a **streaming top‑K heavy‑hitter counter** by combining two well‑known primitives:

1. **Count‑Min Sketch (CMS)** – a sub‑linear memory sketch that yields an **upper‑bound** on the true frequency of any item in O(1) update time.  The classic formulation and error guarantees are described in Cormode & Muthukrishnan, “An Improved Data Stream Summary: The Count‑Min Sketch”, *J. Algorithms* 2005 [doi:10.1016/j.jalgor.2005.01.001] and reproduced in many modern tutorials (e.g., https://github.com/ekzhu/cmu-ml-forked/blob/master/lecture11/cms.py).

2. **Size‑K min‑heap (or Space‑Saving table)** – a deterministic structure that maintains the **current K candidates with the largest estimated counts**.  After each update we query the CMS for the item’s estimated count; if that estimate exceeds the smallest count in the heap we evict the heap’s minimum and insert the new item with its CMS estimate.  This hybrid approach mirrors the design recommended in the System‑Design literature for heavy‑hitters, e.g. “Top K Heavy Hitters” (Raghu’s Notes, 2025) [https://raghu-vijaykumar.github.io/docs/docs/system-design/examples/technical-concepts/top-k-heavy-hitters/].

### Algorithm Outline  

| Step | Description |
|------|-------------|
| **Initialize** | Create a CMS with width *w* and depth *d* (determined by desired error ε and failure probability δ).  Initialise an empty min‑heap of capacity *K*. |
| **Process item `x`** | 1️⃣ For each of the *d* hash functions `h_i`, increment `CMS[i][h_i(x)]`. <br>2️⃣ Estimate `freq̂(x) = min_i CMS[i][h_i(x)]`. <br>3️⃣ If `x` already appears in the heap, update its stored estimate to `freq̂(x)`. <br>4️⃣ Else if heap size `< K`, push `(freq̂(x), x)`. <br>5️⃣ Else if `freq̂(x) > heap.min_count`, pop the minimum and push `(freq̂(x), x)`. |
| **Report** | Return the heap’s elements sorted descending by stored estimate.  The returned list is guaranteed to contain the true top‑K items **up to the CMS over‑estimate error**. |

import math, heapq, sys

class CMS:
    def __init__(self, eps=0.01, delta=0.01):
        self.w = math.ceil(math.e / eps)
        self.d = math.ceil(math.log(1 / delta))
        self.t = [[0] * self.w for _ in range(self.d)]
        self.seeds = [i * 123457 for i in range(self.d)]

    def _h(self, x, i):
        return (hash(x) ^ self.seeds[i]) % self.w

    def add(self, x, c=1):
        for i in range(self.d):
            self.t[i][self._h(x, i)] += c

    def est(self, x):
        return min(self.t[i][self._h(x, i)] for i in range(self.d))


class TopK:
    def __init__(self, K, eps=0.01, delta=0.01):
        self.K = K
        self.cms = CMS(eps, delta)
        self.heap = []                 # (est, item)
        self.best = {}                 # item -> current best estimate

    def ingest(self, x):
        self.cms.add(x)
        e = self.cms.est(x)
        if e > self.best.get(x, 0):
            self.best[x] = e
        heapq.heappush(self.heap, (self.best[x], x))

        # keep only K items
        while len(self.best) > self.K:
            ev, it = heapq.heappop(self.heap)
            if self.best.get(it) == ev:   # stale entries ignored
                del self.best[it]
                break

        # discard stale heap tops
        while self.heap and self.best.get(self.heap[0][1]) != self.heap[0][0]:
            heapq.heappop(self.heap)

    def topk(self):
        # return items sorted by descending estimate
        return [it for _, it in sorted(((v, k) for k, v in self.best.items()), reverse=True)]


def test():
    stream = ['a', 'b', 'a', 'c', 'a', 'b', 'd', 'e', 'b', 'b']
    # true counts: a=3, b=4, c=1, d=1, e=1 → top‑2 = ['b','a']
    th = TopK(K=2, eps=0.001, delta=0.001)   # tiny error → exact counts
    for x in stream:
        th.ingest(x)
    if th.topk() != ['b', 'a']:
        sys.exit('FAIL: expected [\'b\', \'a\'], got ' + str(th.topk()))
    print('SUCCESS')


if __name__ == '__main__':
    test()
