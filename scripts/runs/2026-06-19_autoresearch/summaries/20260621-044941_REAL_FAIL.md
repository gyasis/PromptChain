## Method (cited)

1. **Ingest snapshots** – Load each daily CSV into a *staging* table (or dataframe).  
   - This mirrors the “ingest each daily CSV into a staging table” pattern described in the dbt‑based guide [​Xebia 2026]​ and the Microsoft Fabric tutorial [​Microsoft Learn​]​.

2. **Create a raw‑snapshot view** – For each source CSV create a view that adds a **record_source** column (e.g., `snapshot_date`) and a **hash** column (`md5` of all business columns).  
   - The hash is the change‑detection mechanism used by dbt snapshots [​Xebia 2026]​.

3. **Union the two snapshot views** – Combine the two daily snapshots with `UNION ALL` into a single ordered stream (by `snapshot_date`, then by hash).  

4. **Apply SCD‑2 logic** – Walk the ordered stream row‑by‑row (SQL `LEAD/LAG` or pandas `groupby` + `shift`) and generate the SCD‑2 target columns:
   - **surrogate_key** – monotonically increasing integer per natural key.  
   - **effective_from** – timestamp of the row’s snapshot date.  
   - **effective_to** – timestamp of the *next* change for the same natural key (or `NULL` for the current version).  
   - **is_current** – `TRUE` when `effective_to IS NULL`.  

5. **Upsert into the dimension table** – Insert the newly generated rows into the target dimension (or replace the whole table in a batch load).  

6. **Testing/validation** – Run a unit‑test that feeds two tiny CSV strings through the loader and checks that the output matches the expected SCD‑2 rows (see **Success Bar**).

The overall flow can be realised in pure Python (pandas) for a prototype, or in dbt/SQL for production. The plan below assumes a **Python + pandas** implementation because it is self‑contained and easy to run from a shell command.

**loader.py** – minimal SCD‑2 builder that strips inline `#` comments before parsing the CSVs.

```python
import pandas as pd, hashlib, io, pathlib, sys

def _read(p):
    # drop everything after a ‘#’ on each line, then parse CSV
    txt="\n".join(l.split('#')[0].strip() for l in open(p))
    df=pd.read_csv(io.StringIO(txt))
    df["snapshot_date"]=pd.to_datetime(pathlib.Path(p).stem.split('_')[1])
    return df

def scd2(paths):
    df=pd.concat([_read(p) for p in paths]).sort_values(["product_id","snapshot_date"])
    rows=[]
    for pid,g in df.groupby("product_id",sort=False):
        for i,(_,r) in enumerate(g.iterrows(),1):
            rows.append({
                "surrogate_key":f"{pid}_{i}",
                "product_id":pid,
                "product_name":r.product_name,
                "price":r.price,
                "effective_from":r.snapshot_date,
                "effective_to":pd.NaT,
                "is_current":True})
    return pd.DataFrame(rows)

if __name__=="__main__":
    dim=scd2(sys.argv[1:])
    dim.to_csv("dim.csv",index=False,date_format="%Y-%m-%d")
```
