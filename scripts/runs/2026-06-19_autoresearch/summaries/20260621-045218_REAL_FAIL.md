## Method (cited)  
The **P² (P-squared) algorithm** is a classic online quantile estimator that maintains five markers (minimum, 25 %‑quantile, 50 %‑quantile, 75 %‑quantile, maximum) and updates them incrementally as each sample arrives.  
For the median we specialize the algorithm to the 0.5‑quantile:

1. **Initialisation** – The first five observations are sorted and stored as the five marker heights `h[0] … h[4]`. Their *desired* positions `dn[i]` are set to `i * (n‑1)/4` (where `n` is the current number of samples).  
2. **Update on a new sample `x`**  
   * Locate the cell `k` such that `h[k] ≤ x < h[k+1]`. Increment the actual positions `n_i` for all markers `i > k`.  
   * Increment the desired positions `dn_i` by the fixed increments `inc_i = [0, 0.5, 1.0, 1.5, 2.0]` (these correspond to the 0‑, 0.25‑, 0.5‑, 0.75‑, 1‑quantiles).  
   * For each interior marker `i = 1 … 3` compute the error `e_i = dn_i - n_i`. If `|e_i| ≥ 1` we attempt to move the marker one step toward its desired position using the **P² adjustment formula** (quadratic interpolation). If the interpolated height would violate monotonicity, fall back to a simple linear adjustment.  
3. **Median extraction** – After each update the current median estimate is `h[2]` (the height of the third marker).  

The algorithm is described in the original paper:  
*Jain, R., & Chlamtac, I. (1985). “The P² algorithm for dynamic calculation of quantiles and histograms without storing observations.”*  

A concise, implementation‑focused exposition appears at:  
*https://aakinshin.net/posts/p2-quantile-estimator-intro/*  

Our implementation follows the pseudo‑code from the paper, restricted to the median (0.5‑quantile) for clarity and speed.
