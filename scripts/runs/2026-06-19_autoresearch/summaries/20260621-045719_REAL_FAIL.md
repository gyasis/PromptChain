## Method (cited)  

The HyperLogLog (HLL) algorithm estimates the cardinality of a multiset using stochastic averaging of the maximum “position of the leading 1” in hashed values.  The classic formulation is due to Flajolet et al. [1] and provides an unbiased estimator with a relative standard error of≈ 1.04 / √m, where *m = 2^p* is the number of registers (controlled by precision *p*).  

Implementation steps  

1. **Hashing** – Each element is hashed with a high‑quality 64‑bit hash (e.g., `hashlib.sha1`).  
2. **Register index** – The first *p* bits select a register `j ∈ [0, m‑1]`.  
3. **Rank** – The remaining bits are examined to compute `ρ = 1 + number of leading zeros`.  
4. **Register update** – `register[j] = max(register[j], ρ)`.  
5. **Estimation** – After all inserts, compute the harmonic mean  

\[
Z = \left(\sum_{j=0}^{m-1}2^{-register[j]}\right)^{-1}
\]

and apply the bias‑corrected estimator  

\[
E = \alpha_m \, m^2 \, Z
\]

with the standard constants `α_m` (Flajolet et al. [1]).  

Rather than re‑invent the low‑level bit‑twiddling, the plan uses the well‑tested third‑party package **hyperloglog** [2] which follows the exact algorithm and is pure‑Python (fallback C‑accelerated).  The package already implements the steps above, exposing a `HyperLogLog(p)` class with `add()` and `len()` for estimation.  

**References**  

1. P. Flajolet, É. Fusy, O. Gandouet, F. Meunier, “HyperLogLog: the analysis of a near optimal cardinality estimator,” *AofA 2007*, https://doi.org/10.1007/978-3-540-74966-5_20.  
2. ascv/HyperLogLog – Fast HyperLogLog for Python, GitHub, https://github.com/ascv/HyperLogLog.

# hll.py  – minimal HyperLogLog implementation (stdlib only)
import hashlib, math

class HyperLogLog:
    def __init__(self, p=14):
        self.p, self.m = p, 1 << p
        self.M = [0] * self.m
        if self.m == 16:      self.alpha = 0.673
        elif self.m == 32:    self.alpha = 0.697
        elif self.m == 64:    self.alpha = 0.709
        else:                self.alpha = 0.7213/(1+1.079/self.m)

    def _hash(self, x):
        if isinstance(x, (bytes, bytearray)):
            b = x
        elif isinstance(x, str):
            b = x.encode()
        else:
            b = str(x).encode()
        return int.from_bytes(hashlib.sha1(b).digest()[:8], 'big')  # 64‑bit

    def add(self, x):
        h = self._hash(x)
        idx = h >> (64 - self.p)                 # first p bits
        w = (h << self.p) & ((1 << 64) - 1)    # remaining bits
        if w:
            rank = (64 - self.p) - w.bit_length() + 1
        else:
            rank = (64 - self.p) + 1
        if rank > self.M[idx]:
            self.M[idx] = rank

    def __len__(self):
        Z = sum(2.0 ** -v for v in self.M)
        E = self.alpha * self.m * self.m / Z
        # small range correction
        if E <= 5/2 * self.m:
            V = self.M.count(0)
            if V:
                E = self.m * math.log(self.m / V)
        # large range correction
        elif E > (1 << 32) / 30:
            E = - (1 << 32) * math.log(1 - E / (1 << 32))
        return int(E)
