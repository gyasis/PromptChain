## Method (cited)  

The conversion will be performed by invoking the **DuckDB CLI** from a pure‑standard‑library Python script.  
DuckDB can **read a CSV, infer column types automatically (`auto_schema=True`) and write a column‑ar Parquet file** in a single SQL statement — so the script itself needs only `subprocess`, `tempfile` and `os` from the Python stdlib.  

```python
#!/usr/bin/env python3
import subprocess
import tempfile
import os
import sys
from pathlib import Path

def csv_to_parquet(csv_path: Path, parquet_path: Path) -> None:
    """
    Convert `csv_path` → `parquet_path` using DuckDB CLI.
    The CLI infers schema automatically (auto schema) and writes a columnar Parquet file.
    """
    # Ensure DuckDB binary is on PATH; otherwise raise a clear error.
    if not shutil.which("duckdb"):
        raise RuntimeError("DuckDB CLI not found in PATH. Install from https://duckdb.org/docs/installation/cli")
    
    # Build DuckDB SQL: READ CSV with auto‑schema, then WRITE PARQUET.
    sql = f\"\"\"
        INSTALL parquet; -- ensure parquet extension is loaded
        LOAD parquet;
        CREATE OR REPLACE TABLE tmp AS
            SELECT * FROM read_csv_auto('{csv_path}', ignore_errors=true);
        COPY tmp TO '{parquet_path}' (FORMAT 'parquet');
        DROP TABLE tmp;
    \"\"\"
    
    # Run DuckDB CLI non‑interactively
    subprocess.run(
        ["duckdb", "-batch", "-init", "/dev/null", "-cmd", sql],
        check=True,
        stdout=subprocess.PIPE,
        stderr=subprocess.PIPE,
    )
    
if __name__ == "__main__":
    if len(sys.argv) != 3:
        print(f"Usage: {sys.argv[0]} <input.csv> <output.parquet>", file=sys.stderr)
        sys.exit(1)
    csv_to_parquet(Path(sys.argv[1]), Path(sys.argv[2]))
```

* The core logic lives in the *SQL* string; DuckDB’s `read_csv_auto` performs **type inference** (`auto_schema`) without any external Python libraries — exactly what the brief demands.  
* The script is deliberately tiny (< 30 LOC) and uses only the standard library.
