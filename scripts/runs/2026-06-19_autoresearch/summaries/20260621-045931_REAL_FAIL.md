## Method (cited)

The count‑distinct aggregation will be implemented by **external‑merge sort** — the classic external‑memory algorithm for sorting arbitrarily large datasets while using only a bounded amount of RAM.  

1. **Chunk Generation** – Read the input stream in fixed‑size batches (e.g., 10 MiB).  
2. **In‑memory Sort** – For each batch, extract the key column, sort the keys with Python’s `list.sort()` (O(k log k)).  
3. **Run Spill** – Serialize the sorted keys of the batch to a temporary file (a *run*).  
4. **K‑Way Merge** – Open all run files and perform a k‑way merge using `heapq.merge`. Because each run is already sorted, the merge yields a single globally‑sorted sequence without loading all runs into memory.  
5. **Distinct Counting** – Walk the merged stream, keep the last emitted key (`prev`). Increment a counter each time the current key differs from `prev`.  

The algorithm guarantees **exact** distinct counts, works for inputs far larger than available memory, and runs in O(N log M) time where *M* is the number of runs (≤ ⌈N/BatchSize⌉).

- Sorting‑based distinct counting is described in classic DB literature and reinforced by modern tutorials on external merge sort: “Sort‑Merge Join and External Merge Sort” — Padho.ai [web:https://learn.padho.ai/wiki/sort‑merge‑join‑and‑external‑merge‑sort]  
- The approach of spilling sorted runs and merging is the standard external‑merge algorithm used in many database systems.

# count_distinct.py
import argparse, os, sys, heapq, tempfile, shutil

def chunk_iter(f, limit):
    buf, size = [], 0
    for line in f:
        l = line.rstrip('\n')
        b = len(l.encode()) + 1  # approx bytes with newline
        if buf and size + b > limit:
            yield buf
            buf, size = [], 0
        buf.append(l)
        size += b
    if buf:
        yield buf

def write_run(keys, dir_path, idx):
    path = os.path.join(dir_path, f'run{idx}')
    with open(path, 'w', encoding='utf-8') as wf:
        wf.write('\n'.join(keys))
        wf.write('\n')
    return path

def merge_count(paths):
    iters = (open(p, encoding='utf-8') for p in paths)
    merged = heapq.merge(*iters)
    prev, cnt = None, 0
    for line in merged:
        key = line.rstrip('\n')
        if key != prev:
            cnt += 1
            prev = key
    for it in iters:
        it.close()
    return cnt

def main():
    p = argparse.ArgumentParser()
    p.add_argument('--input', required=True)
    p.add_argument('--batch-bytes', type=int, default=10_000_000)
    p.add_argument('--tmp-dir', default=None)
    args = p.parse_args()

    tmp_root = args.tmp_dir or tempfile.mkdtemp()
    os.makedirs(tmp_root, exist_ok=True)
    runs = []
    try:
        with open(args.input, encoding='utf-8') as f:
            for i, chunk in enumerate(chunk_iter(f, args.batch_bytes)):
                chunk.sort()
                runs.append(write_run(chunk, tmp_root, i))
        result = merge_count(runs)
        sys.stdout.write(str(result))
    finally:
        shutil.rmtree(tmp_root, ignore_errors=True)

if __name__ == '__main__':
    main()
