## Method (cited)  

1. **Pre‑process the CSV** – read each row, drop pure‑empty columns, lower‑case all text, and split the remaining fields into *shingles* (5‑gram character tokens). Each row is therefore represented as a Python `set` of shingles.  

2. **Create MinHash signatures** – for every row‑set generate a `datasketch.MinHash` object with `num_perm=128`. The `datasketch` library implements the classic *MinHash* sketch described by Broder 1997 [citation].  

3. **Insert signatures into an LSH index** – build a `datasketch.MinHashLSH` with  
   ```python
   lsh = MinHashLSH(threshold=0.8, num_perm=128)   # 80 % Jaccard similarity ≈ “near‑duplicate”
   ```  
   and add each signature keyed by the original row index.  

4. **Query for candidate groups** – for every row, query `lsh.query(minhash)` to obtain all indices whose Jaccard similarity ≥ 0.8. Collapse each transitive closure of overlapping groups into a single representative (the first index in the group).  

5. **Compute deduplication ratio** –  
   \[
   \text{dedup\_ratio}=1-\frac{\text{# unique rows after collapse}}{\text{# rows in original CSV}}
   \]  

6. **Report** – print the ratio (rounded to 4 dp) and optionally a brief listing of the duplicate groups.  

The workflow follows the well‑established practice of *MinHash + LSH* for large‑scale similarity joins on tabular data [web:https://dl.acm.org/doi/fullHtml/10.1145/3377455] and of indexing sets with MinHash LSH for near‑duplicate detection in data‑lake tables [web:https://ekzhu.com/papers/Zhu_Erkang_201906_PhD_thesis.pdf].

import csv, sys, random, itertools

K, NUM, B = 5, 64, 8          # shingle size, MinHash perms, LSH bands
MAX = (1 << 31) - 1

def shingles(s):
    s = s.lower()
    return {s[i:i+K] for i in range(len(s)-K+1)} if len(s) >= K else {s}

def perms():
    random.seed(42)
    return [(random.randint(1, MAX), random.randint(0, MAX)) for _ in range(NUM)]

def mh(sig):
    h = []
    for a, b in sig:
        m = 2**63-1
        for w in words:
            v = (a * hash(w) + b) & 0xffffffff
            if v < m: m = v
        h.append(m)
    return h

def lsh(idx_sig):
    r = NUM // B
    buckets = {}
    for i, sig in idx_sig:
        for b in range(B):
            band = tuple(sig[b*r:(b+1)*r])
            key = (b, hash(band))
            buckets.setdefault(key, []).append(i)
    return buckets

def dedup_ratio(path, thr=0.8):
    rows = list(csv.DictReader(open(path, newline='', encoding='utf8')))
    global words
    words = [shingles(' '.join(filter(None, r.values()))) for r in rows]
    per = perms()
    idx_sig = [(i, mh(per)) for i, _ in enumerate(words)]
    buckets = lsh(idx_sig)
    parent = list(range(len(rows)))

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    def union(a, b):
        ra, rb = find(a), find(b)
        if ra != rb: parent[rb] = ra

    r = NUM // B
    for i, sig in idx_sig:
        cand = set()
        for b in range(B):
            key = (b, hash(tuple(sig[b*r:(b+1)*r])))
            cand.update(buckets.get(key, []))
        cand.discard(i)
        for j in cand:
            s1, s2 = words[i], words[j]
            inter, uni = len(s1 & s2), len(s1 | s2)
            if uni and inter / uni >= thr:
                union(i, j)

    uniq = len({find(i) for i in range(len(rows))})
    return 1 - uniq / len(rows)

if __name__ == '__main__':
    print(f'{dedup_ratio(sys.argv[1]):.4f}')
