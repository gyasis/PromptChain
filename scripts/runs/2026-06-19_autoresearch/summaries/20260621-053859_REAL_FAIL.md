## Method (cited)

1. **Algorithm choice** – Use the **HyperLogLog (HLL)** probabilistic cardinality estimator as described in the original paper *Flajolet, P., Fusy, É., Gandouet, O., & Meunier, F. (2007). HyperLogLog: the analysis of a near optimal cardinality estimator.*【cite:flajolet2007】.  

2. **Library** – Leverage the well‑tested Python implementation from **ascv/HyperLogLog** (BSD‑3 license) which provides a `HyperLogLog(p)` class with `add(item)` and `cardinality()` methods【cite:ascv2023】.  

3. **Precision selection** – The relative standard error (RSE) of HLL is `≈ 1.04 / sqrt(2**p)`.  
   * To stay below the 5 % error budget we need `1.04 / sqrt(2**p) ≤ 0.05` → `2**p ≥ (1.04/0.05)² ≈ 435`.  
   * The smallest integer `p` satisfying this is `p = 9` (`2⁹ = 512`).  
   * We therefore instantiate `HyperLogLog(p=9)` for all experiments.  

4. **Verification procedure** –  
   * Generate a deterministic pseudo‑random stream of `N = 10 000` integers with a known unique count `U`.  
   * Insert each integer into the HLL instance.  
   * Retrieve `est = hll.cardinality()`.  
   * Compute relative error: `err = abs(est - U) / U`.  
   * Repeat the whole experiment `R = 100` times (different seeds) and collect errors.  

5. **Success criterion** – The **95‑th percentile** of the `R` errors must be ≤ 0.05 (5 %). This mirrors the usual probabilistic guarantee of HLL while giving a concrete, reproducible test.

# hll.py
import hashlib, math

class HyperLogLog:
    def __init__(self, p=9):
        self.p, self.m = p, 1 << p
        self.reg = [0] * self.m
        self.alpha = {16:0.673,32:0.697,64:0.709}.get(self.m,
                     0.7213/(1+1.079/self.m))

    def _rank(self, w, maxbits):
        if w == 0:
            return maxbits + 1
        return maxbits - w.bit_length() + 1

    def add(self, x):
        h = int(hashlib.sha256(str(x).encode()).hexdigest(), 16)
        idx = (h >> (256 - self.p)) & (self.m - 1)
        w = h & ((1 << (256 - self.p)) - 1)
        r = self._rank(w, 256 - self.p)
        if r > self.reg[idx]:
            self.reg[idx] = r

    def cardinality(self):
        Z = sum(2.0 ** -v for v in self.reg)
        E = self.alpha * self.m * self.m / Z
        if E <= 5/2 * self.m:
            V = self.reg.count(0)
            return int(self.m * math.log(self.m / V)) if V else int(E)
        if E <= (1/30) * (1 << 32):
            return int(E)
        return int(- (1 << 32) * math.log(1 - E / (1 << 32)))
