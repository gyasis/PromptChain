## Method (cited)  

We will implement a classic Bloom filter whose parameters are derived from the **expected number of items** `n` and the **target false‑positive probability** `p`.  

1. **Parameter calculation** – Using the well‑known formulas   

   *`m = - (n * ln p) / (ln 2)^2`* (size of the bit array)  

   *`k = (m / n) * ln 2`* (number of hash functions)  

   This derivation is described in the Bloom‑filter literature and reproduced in the GeeksforGeeks tutorial [1].  

2. **Hash functions** – We will employ `k` independent hash values generated from the built‑in `hashlib.sha256`. For each seed `i` (0 … k‑1) we hash the concatenation of the element string and the seed, then take the result modulo `m`. This technique is recommended for deterministic, fast hashing and avoids the need for external libraries.  

3. **Insertion** – For each element `x` in the input set, compute its `k` hash indices and set the corresponding bits in a `bytearray` of length `m`.  

4. **Query** – An element is reported **present** if **all** its `k` bits are set; otherwise it is **absent**. By construction there are *no false negatives*; false positives occur when bits from other elements collide.  

5. **Empirical false‑positive measurement** – After building the filter we will generate a large batch (e.g., 10 000) of random strings that were **not** inserted, query each of them, and compute  

   `observed_fp = (num_false_positives) / (num_queries)`  

   This observed rate will be compared against the target `p`. The approach of measuring the empirical rate and contrasting it with the theoretical expectation follows the guidance in the ByteDrum article [2] and the corpus discussion of Bloom‑filter behavior [3].  

6. **Reporting** – The script will print:  

   * `n`, `p`, calculated `m` and `k`  
   * `observed_fp`  
   * `abs(observed_fp - p)`  

   If the absolute difference exceeds a tolerance (e.g., `0.01`), the script will exit with a non‑zero status, signalling that the implementation does not meet the target false‑positive bound.

# bloom.py
import math,hashlib
class Bloom:
    def __init__(self,n,p):
        self.m=math.ceil(-(n*math.log(p))/((math.log(2))**2))
        self.k=math.ceil((self.m/n)*math.log(2))
        self.b=bytearray(self.m//8+1)
    def _h(self,x):
        for i in range(self.k):
            yield int(hashlib.sha256((x+str(i)).encode()).hexdigest(),16)%self.m
    def add(self,x):
        for i in self._h(x):self.b[i//8]|=1<<(i%8)
    def __contains__(self,x):
        return all(self.b[i//8]&(1<<(i%8)) for i in self._h(x))
