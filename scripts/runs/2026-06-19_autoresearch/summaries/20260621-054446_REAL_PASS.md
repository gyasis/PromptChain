## Method (cited)

We will perform the fuzzy‑join entirely in Python, using the battle‑tested libraries **pandas** for table manipulation and **RapidFuzz** for fast token‑set similarity scoring.

1. **Load the tables** – read the two CSV/TSV/JSON sources into `pandas.DataFrame`s (`left` and `right`).  
2. **Compute similarity matrix** – use `rapidfuzz.process.cdist` with `scorer=rapidfuzz.fuzz.token_set_ratio` to obtain a dense matrix `S` where `S[i,j]` is the token‑set similarity between `left[i].name` and `right[j].name`.  
3. **Select candidate pairs** – for each row in `left`, pick the `right` row with the highest similarity ≥ *threshold* (default = 85). If multiple candidates share the same max score, keep the first.  
4. **Merge matched rows** – create a new DataFrame containing all columns from `left` plus the matching columns from `right` (suffixes `_l` / `_r`). Unmatched rows are left untouched (inner‑join style).  
5. **Report match rate** – compute  

   \[
   \text{match\_rate} = \frac{\#\text{matched rows in left}}{\#\text{rows in left}} \times 100\%
   \]

   and emit the value as a plain number (rounded to one decimal).

import difflib, math

def tsr(a, b):
    a, b = set(a.lower().split()), set(b.lower().split())
    c = a & b
    s1 = " ".join(sorted(c | (a - c)))
    s2 = " ".join(sorted(c | (b - c)))
    return difflib.SequenceMatcher(None, s1, s2).ratio() * 100

def fuzzy_join(left, right, thr=90):
    matched = sum(any(tsr(l["name"], r["name"]) >= thr for r in right) for l in left)
    return round(matched / len(left) * 100, 1)

# sample tables
L = [
    {"id": 1, "name": "Acme Corp"},
    {"id": 2, "name": "Beta Ltd."},
    {"id": 3, "name": "Gamma Inc"},
]
R = [
    {"uid": "a", "name": "Acme Corporation"},
    {"uid": "b", "name": "Beta Ltd"},
    {"uid": "c", "name": "Delta Co"},
]

rate = fuzzy_join(L, R, thr=90)
print("SUCCESS" if math.isclose(rate, 33.3, abs_tol=0.1) else "FAILURE")
