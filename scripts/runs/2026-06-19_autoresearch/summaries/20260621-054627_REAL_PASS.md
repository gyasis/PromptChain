## Method (cited)  
We will implement the classic **P² (P‑square) quantile estimator** [1] to maintain a running approximation of the median (the 0.5‑quantile) without storing the full data stream.  

1. **Initialization** – The first five samples are sorted and used to initialise five markers that represent the 0‑th, 0.25‑th, 0.5‑th, 0.75‑th and 1‑st quantiles. Their heights (`q`) and positions (`n`) are stored.  

2. **Update for each new observation `x`**  
   * Locate the cell in which `x` falls and increment the positions of all markers to the right of that cell.  
   * Increment the *desired* positions `n'` of each marker by its quantile probability `p_i` (`p = [0, 0.25, 0.5, 0.75, 1]`).  
   * For each interior marker `i = 2,3,4` compute the deviation `d = n'_i - n_i`. If `|d| ≥ 1`, move the marker one step toward its desired position using the **parabolic interpolation** formula described in the original paper [1]. If the parabolic estimate would violate monotonicity, fall back to the **linear** formula.  

3. **Median retrieval** – The height of the third marker (`q[2]`) is the current approximation of the streaming median.  

The algorithm runs in **O(1)** time per sample and **O(1)** memory, satisfying the “do not store all values” requirement.  

**Citations**  

1. Jain, R.; Chlamtac, I. (1985). *The P² algorithm for dynamic calculation of quantiles and histograms without storing observations*. Communications of the ACM, 28(10), 1076‑1085. doi:10.1145/4372.4373.  
   (Also explained in a friendly blog post: https://aakinshin.net/posts/p2-quantile-estimator-intro/)

class P2Median:
    def __init__(self):
        self._s = []
        self.q = [0]*5
        self.n = [0]*5
        self.np = [0]*5
        self.p = [0, .25, .5, .75, 1]
        self.init = False

    def add(self, x):
        x = float(x)
        if not self.init:
            self._s.append(x)
            if len(self._s) == 5:
                self._s.sort()
                self.q = self._s[:]
                self.n = [1, 2, 3, 4, 5]
                self.np = [1 + p*4 for p in self.p]
                self.init = True
            return

        # locate cell
        if x < self.q[0]:
            self.q[0] = x; k = 0
        elif x >= self.q[4]:
            self.q[4] = x; k = 3
        else:
            k = 0
            while x >= self.q[k+1]: k += 1

        for i in range(k+1, 5): self.n[i] += 1
        for i in range(5): self.np[i] += self.p[i]

        for i in range(1, 4):
            d = self.np[i] - self.n[i]
            if (d >= 1 and self.n[i+1]-self.n[i] > 1) or (d <= -1 and self.n[i-1]-self.n[i] < -1):
                s = 1 if d > 0 else -1
                qi, qi1, qim = self.q[i], self.q[i+1], self.q[i-1]
                ni, nip, nim = self.n[i], self.n[i+1], self.n[i-1]
                qp = qi + s/(nip-nim)*((ni-nim+s)*(qi1-qi)/(nip-ni)+(nip-ni-s)*(qi-qim)/(ni-nim))
                if qim < qp < qi1:
                    self.q[i] = qp
                else:
                    self.q[i] = qi + s*(self.q[i+s]-qi)/(self.n[i+s]-ni)
                self.n[i] += s

    def median(self):
        if not self.init:
            t = sorted(self._s)
            m = len(t)//2
            return (t[m] + t[-m-1])/2 if len(t)%2==0 else t[m]
        return self.q[2]
