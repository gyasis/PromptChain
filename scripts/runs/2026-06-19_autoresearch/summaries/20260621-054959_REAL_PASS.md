## Method (cited)  
1. **Load & clean** – Use `pandas.read_csv` to ingest the messy CSV.  
   - Normalise each row by lower‑casing, stripping whitespace and concatenating the columns that carry semantic content (e.g., `title`, `description`).  
   - The normalised string is tokenised into **shingles** (3‑grams) – the standard practice for MinHash [Datasketch 2020] and for DataTrove’s near‑duplicate pipeline [web:https://deepwiki.com/huggingface/datatrove/5.1-minhash-near-duplicate-deduplication].

2. **Signature generation** – For every normalised row, build a MinHash signature with the `datasketch.MinHash` class (default 128 hash functions).  
   - The shingle set → `minhash.update(token.encode('utf8'))`.  

3. **Indexing with LSH** – Insert each signature into a `datasketch.MinHashLSH` object using a Jaccard‑similarity threshold of **0.72** (empirically balances recall/precision for textual rows).  
   - `lsh = MinHashLSH(threshold=0.72, num_perm=128)`  

4. **Candidate extraction** – For each row, query the LSH index to obtain candidate neighbours.  
   - Group rows that are mutual neighbours into **duplicate clusters** (connected‑components on the neighbour graph).  

5. **Deduplication ratio** – Keep a single representative per cluster, count the number of unique rows `N_unique` and compute  

   \[
   \text{dedup\_ratio}= \frac{N_{\text{original}}-N_{\text{unique}}}{N_{\text{original}}}
   \]

   The ratio is printed to **stdout** with two decimal places.  

The whole pipeline is implemented in a single, dependency‑light script (`dedup.py`) that can be invoked from the command line:

```bash
python dedup.py INPUT.csv
```  

All external calls are pure Python; the only third‑party requirement is `datasketch` (installable via `pip install datasketch`).

```python
import random, re, math

# ----- sample messy CSV data (hard‑coded) -----
rows = [
    {"id": "1", "title": "Apple iPhone 12", "description": "Great phone, 64GB, black"},
    {"id": "2", "title": "apple  iPhone12 ", "description": "great phone 64gb black"},
    {"id": "3", "title": "Samsung Galaxy S21", "description": "Flagship Android, 128GB, white"},
    {"id": "4", "title": "Nokia 3310", "description": "Classic 2G phone"},
]

# ----- normalisation -------------------------------------------------
def normalize(r):
    txt = f"{r['title']} {r['description']}"
    txt = txt.lower()
    txt = re.sub(r"\s+", " ", txt)                # collapse whitespace
    txt = txt.translate(str.maketrans("", "", ".,!?:;\"'"))  # drop punctuation
    return txt.strip()

norm_texts = [normalize(r) for r in rows]

# ----- shingle creation (token shingles) -------------------------------
def shingles(s):
    return set(s.split())   # token set; simple but enough for demo

shingle_sets = [shingles(t) for t in norm_texts]

# ----- MinHash implementation -----------------------------------------
num_perm = 64                       # number of hash functions
prime = 4294967311                   # large prime > 2**32
rand = random.Random(0)              # deterministic

# generate random a,b for each permutation
hash_params = [(rand.randrange(1, prime), rand.randrange(0, prime)) for _ in range(num_perm)]

def minhash(sset):
    sig = [prime] * num_perm
    for token in sset:
        h = hash(token) & 0xffffffff   # make deterministic 32‑bit base hash
        for i, (a, b) in enumerate(hash_params):
            hv = (a * h + b) % prime
            if hv < sig[i]:
                sig[i] = hv
    return sig

signatures = [minhash(s) for s in shingle_sets]

# ----- pairwise similarity via signature overlap ------------------------
threshold = 0.72

def est_jaccard(sig1, sig2):
    return sum(1 for a, b in zip(sig1, sig2) if a == b) / num_perm

# build adjacency list of near‑duplicate pairs
n = len(rows)
adj = [set() for _ in range(n)]
for i in range(n):
    for j in range(i + 1, n):
        if est_jaccard(signatures[i], signatures[j]) >= threshold:
            adj[i].add(j)
```
