|------|--------|--------|
| 1️⃣ | **Parameter calculation** | For a desired false‑positive rate `p` and an expected element count `n`, compute the optimal bit‑array size `m = ceil(-n * log(p) / (log(2)**2))` and the optimal number of hash functions `k = round((m / n) * log(2))`. |
| 2️⃣ | **Hash family** | Use a pair of fast, deterministic hash functions (`hashlib.sha256` with different salts) to generate `k` independent indices via the double‑hashing technique: `h_i(x) = (h1(x) + i * h2(x)) % m`. This avoids the need for `k` separate hash implementations while preserving independence guarantees. |
| 3️⃣ | **Bit‑array** | Store the filter as a `bytearray` (or `bitarray` if the extra dependency is acceptable). Setting and checking bits is performed with bit‑wise operations (shift & mask). |
| 4️⃣ | **Insertion** | For each element `x` in the known set, compute its `k` indices and set the corresponding bits to 1. |
| 5️⃣ | **Query** | To test membership, compute the same `k` indices and verify that **all** bits are set. If any are 0, the element is definitely absent; otherwise it **might** be present. |
| 6️⃣ | **Empirical false‑positive measurement** | Generate a disjoint test set (e.g., `range(n, 2n)`). Query each element; count the number of *positives* on these unseen items. The empirical false‑positive rate is `fp_count / n`. |
| 7️⃣ | **Verification against target** | Compare the empirical rate to the target `p`. The implementation is considered successful when the empirical rate ≤ `p * 1.25` (allowing a 25 % statistical tolerance for the small test size). |

import hashlib, math

class BF:
    def __init__(self, n, p):
        self.m = math.ceil(-n*math.log(p)/ (math.log(2)**2))
        self.k = max(1, round(self.m/n*math.log(2)))
        self.b = bytearray((self.m+7)//8)
    def _h(self, x):
        h1 = int(hashlib.sha256(b"s1"+x).hexdigest(),16)
        h2 = int(hashlib.sha256(b"s2"+x).hexdigest(),16)
        for i in range(self.k):
            yield (h1+i*h2)%self.m
    def add(self,x):
        for p in self._h(x): self.b[p//8]|=1<<(p%8)
    def __contains__(self,x):
        return all((self.b[p//8]>> (p%8))&1 for p in self._h(x))

N, T = 10000, 0.02               # expected elems, target false‑pos rate
bf = BF(N,T)
for i in range(N): bf.add(str(i).encode())
fp = sum(str(i).encode() in bf for i in range(N,2*N))
emp = fp/N
print(f"empirical false‑positive rate = {emp:.4f}")
print("SUCCESS" if emp<=T*1.25 else "FAILURE")
