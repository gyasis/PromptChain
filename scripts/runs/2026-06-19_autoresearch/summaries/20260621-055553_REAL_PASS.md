## Method (cited)

1. **Read the two input tables** – they can be supplied as CSV files or as `pandas.DataFrame` objects.  
2. **Pre‑process the name columns** – strip whitespace and normalise case (`str.lower().strip()`).  
3. **Pairwise scoring** – for each left‑row compute the **RapidFuzz** `token_set_ratio` against every right‑row name.  
   ```python
   from rapidfuzz import fuzz
   score = fuzz.token_set_ratio(left_name, right_name)
   ```  
   *Token‑set ratio* treats the strings as unordered token sets, ignoring duplicate words – exactly what is required for noisy names [Towards Data Science, 2025]​[1].
4. **Threshold filtering** – retain pairs whose score ≥ `threshold` (default 70 % as recommended for fuzzy joins​[Predictive Hacks, 2023]​[2]).
5. **Select best match per left row** – among the surviving candidates keep the right row with the highest score (ties are broken by the first occurrence).  
6. **Perform the join** – create the merged table by concatenating the selected right‑row to the left‑row.  
7. **Report match rate** –  

   \[
   \text{match‑rate}= \frac{\text{# left rows that obtained a match}}{\text{total # left rows}}
   \]

8. **CLI entry‑point** – `fuzzy_join.py` implements the whole pipeline and prints a single line:

   ```
   Match rate: <float>
   ```

The implementation lives in a single module (`fuzzy_join.py`) with a reusable function `fuzzy_join_rate(left, right, left_on, right_on, threshold=70)` that returns the numeric match rate, and a `__main__` block that parses CLI arguments, calls the function, and prints the result.

import difflib, itertools, math

def _tok_set_ratio(a, b):
    a, b = a.lower(), b.lower()
    sa, sb = a.split(), b.split()
    ia, ib = set(sa), set(sb)
    inter = sorted(ia & ib)
    d1 = sorted(ia - ib)
    d2 = sorted(ib - ia)
    def ratio(x, y):
        return difflib.SequenceMatcher(None, x, y).ratio() * 100
    s_int = " ".join(inter)
    s1 = " ".join(inter + d1)
    s2 = " ".join(inter + d2)
    return max(ratio(s1, s2), ratio(s_int, s1), ratio(s_int, s2))

def fuzz_join_rate(L, R, lcol, rcol, thr=70):
    matches = 0
    for l in L:
        best = 0
        for r in R:
            sc = _tok_set_ratio(l[lcol], r[rcol])
            if sc > best:
                best = sc
        if best >= thr:
            matches += 1
    return matches / len(L) if L else 0
