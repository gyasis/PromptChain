## Chosen Approach  
Implement the classic P² algorithm – initialize five markers with the first five samples (sorted) and set the target quantile p to 0.5 for the median. For each new value, increment the desired positions of the markers, shift any markers whose actual positions diverge from the desired ones, and adjust their heights using the piecewise‑parabolic interpolation formulas described in the original P² paper (linear fallback when the interpolation would violate monotonicity). This yields an exact‑size (five‑value) streaming median estimator that never stores the full data set – just the five marker heights and their position counters, giving O(1) memory and O(1) per‑sample time 【web:https://aakinshin.net/posts/p2-quantile-estimator-intro/】.

## Method (cited)  
Implement the classic **P² quantile estimator** for the 0.5‑quantile (median) as described by Jain & Chlamtac (1985) and summarized in Akinshin’s tutorial【web:https://aakinshin.net/posts/p2-quantile-estimator-intro/】.  

The algorithm works in **O(1) memory** and **O(1) time per sample**:  

1. **Initialization** – consume the first five values, sort them, and store them as the five marker heights `q[0] … q[4]`. Their initial positions are `n[i] = i+1` (i‑based). The desired positions for the median are `np[i] = 1 + 2·p·i` where `p = 0.5`.  

2. **Update per incoming sample `x`**  
   * Locate the bucket (`k`) such that `q[k] ≤ x < q[k+1]`. Increment all marker positions `n[i]` for `i > k`.  
   * Increment the desired positions `np[i]` by `p` (for `i = 1,2,3`) or `1‑p` (for the symmetric side).  
   * For each interior marker `i = 1..3`, compute the desired shift `d = np[i] – n[i]`. If `|d| ≥ 1` and the neighboring markers permit movement, adjust `q[i]` using the **parabolic formula**  

   \[
   q_i' = q_i + \frac{d}{n_{i+1}-n_{i-1}}
      \left[(n_i-n_{i-1}+d)(q_{i+1}-q_i)/(n_{i+1}-n_i)
            +(n_{i+1}-n_i-d)(q_i-q_{i-1})/(n_i-n_{i-1})\right]
   \]  

   * If the parabolic update would violate monotonicity (`q_{i-1} < q_i' < q_{i+1}` fails), fall back to the **linear update**  

   \[
   q_i' = q_i + d \cdot \frac{q_{i+1}-q_i}{n_{i+1}-n_i}
   \]  

   * After adjusting the height, set `n[i] = n[i] + sign(d)`.  

3. **Result** – after processing the stream, `q[2]` holds the estimated median.  

The implementation will be packaged as a small, pure‑Python class `P2Median` exposing `add(value)` and `median()` methods. No external libraries are required.

import math

class P2Median:
    def __init__(self):
        self.buf = []
        self.q = [0.0]*5      # marker heights
        self.n = [0]*5        # marker positions
        self.np = [0.0]*5     # desired positions
        self.p = 0.5

    def _init(self):
        self.buf.sort()
        for i in range(5):
            self.q[i]=self.buf[i]
            self.n[i]=i+1
        self.np[0]=1
        self.np[1]=1+2*self.p
        self.np[2]=1+4*self.p
        self.np[3]=3+2*self.p
        self.np[4]=5

    def add(self,x):
        if len(self.buf)<5:
            self.buf.append(x)
            if len(self.buf)==5: self._init()
            return
        # locate k
        if x<self.q[0]:
            self.q[0]=x; k=0
        elif x>=self.q[4]:
            self.q[4]=x; k=3
        else:
            k=0
            while not(self.q[k]<=x<self.q[k+1]): k+=1
        for i in range(k+1,5): self.n[i]+=1
        for i in (1,2): self.np[i]+=self.p
        self.np[3]+=(1-self.p)
        # adjust interior markers
        for i in (1,2,3):
            d=self.np[i]-self.n[i]
            if abs(d)>=1:
                if (d>0 and self.n[i+1]-self.n[i]>1) or (d<0 and self.n[i]-self.n[i-1]>1):
                    s=math.copysign(1,d)
                    # parabolic prediction
                    qip=self.q[i]+s/(self.n[i+1]-self.n[i-1])*(
                        (self.n[i]-self.n[i-1]+s)*(self.q[i+1]-self.q[i])/(self.n[i+1]-self.n[i])+
                        (self.n[i+1]-self.n[i]-s)*(self.q[i]-self.q[i-1])/(self.n[i]-self.n[i-1])
                    )
                    if self.q[i-1]<qip<self.q[i+1]:
                        self.q[i]=qip
                    else:
                        self.q[i]+=s*(self.q[i+int(s)]-self.q[i])/(self.n[i+int(s)]-self.n[i])
                    self.n[i]+=int(s)

    def median(self):
        if len(self.buf)<5:
            s=sorted(self.buf)
            m=len(s)//2
            return (s[m]+s[-m-1])/2.0
        return self.q[2]
