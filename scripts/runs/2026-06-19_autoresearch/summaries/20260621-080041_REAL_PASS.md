## Method (cited)  

1. **Data structure selection** – Use a classic Bloom filter: a fixed‑size bit array of length *m* and *k* independent hash functions. This design guarantees *no false negatives* while allowing a tunable false‑positive probability *p* ≈ \((1-e^{-kn/m})^{k}\) [Wikipedia 2024‑06‑21].  

2. **Hash function implementation** – Derive *k* hash values from a single cryptographic hash (SHA‑256) by salting with the index *i* (double‑hash technique). For an element `x` the *i*‑th hash is:  

   ```
   h1 = int(sha256(x).hexdigest()[:16], 16)
   h2 = int(sha256(x).hexdigest()[16:32], 16)
   idx_i = (h1 + i * h2) % m          # i = 0 … k‑1
   ```  

   This method is proven to produce *k* indistinguishable, uniformly distributed indices while using only one underlying hash computation [Kirsch & Mitzenmacher 2006].  

3. **Insertion** – For each element `e` in the input set *S*, compute the *k* indices and set the corresponding bits in the bit array.  

4. **Query** – To test membership of element `q`, compute its *k* indices; return **True** only if all *k* bits are set, otherwise **False**.  

5. **Parameter tuning** –  
   * Choose target false‑positive rate `p_target`.  
   * Compute optimal *k* = round((m/n)·ln2) and minimal *m* = ceil(-(n·ln p_target) / (ln2)²) where *n* = |S| (standard Bloom‑filter formulas).  
   * Build the filter with the computed *m* and *k* and empirically verify the observed rate.  

6. **Measurement of false‑positive rate** –  
   * Generate a large test set *T* of random strings that are guaranteed **not** to belong to *S* (e.g., using UUIDs).  
   * Query the Bloom filter for each element of *T*.  
   * Empirical rate = (number of queries returning **True**) / |T|.  
   * Assert that empirical rate ≤ `p_target * (1 + ε)` with a small tolerance ε (e.g., 0.05).  

7. **Packaging** – Expose a small, self‑contained Python class `BloomFilter` with methods `add(item)`, `__contains__(item)`, and a helper `false_positive_rate(test_items)` for reuse in downstream projects.

import hashlib, sys, uuid, math, random

# ---------- Bloom filter ----------
class BloomFilter:
    def __init__(self, m, k):
        self.m, self.k = m, k
        self.bits = 0                     # bit‑array stored as an int

    def _hashes(self, item):
        h = hashlib.sha256(item.encode()).digest()
        h1 = int.from_bytes(h[:16], 'big')
        h2 = int.from_bytes(h[16:], 'big')
        for i in range(self.k):
            yield (h1 + i * h2) % self.m

    def add(self, item):
        for idx in self._hashes(item):
            self.bits |= 1 << idx

    def __contains__(self, item):
        return all(((self.bits >> idx) & 1) for idx in self._hashes(item))

    def false_positive_rate(self, test_items):
        fp = sum(1 for x in test_items if x in self)
        return fp / len(test_items)


# ---------- Test harness ----------
def run_test():
    # target false‑positive probability and tolerance
    p_target = 0.02          # 2 %
    eps = 0.10               # allow 10 % overshoot

    # deterministic small data set
    data = [f"item{i}" for i in range(30)]

    n = len(data)
    # optimal size m and number of hash functions k (standard formulas)
    m = math.ceil(-(n * math.log(p_target)) / (math.log(2) ** 2))
    k = max(1, round((m / n) * math.log(2)))   # at least 1

    bf = BloomFilter(m, k)
    for x in data:
        bf.add(x)

    # 1️⃣  all inserted items must be reported present (no false negatives)
    for x in data:
        if x not in bf:
            print(f"FAILURE: false negative for '{x}'")
            sys.exit(1)

    # 2️⃣  generate many items guaranteed *not* to be in the set
    test_sz = 5000
    test_items = []
    while len(test_items) < test_sz:
        cand = str(uuid.uuid4())
        if cand not in data:          # practically always true
            test_items.append(cand)

    fp_rate = bf.false_positive_rate(test_items)

    # 3️⃣  verify empirical rate is within tolerated bound
    if fp_rate <= p_target * (1 + eps):
        print(f"SUCCESS: false‑positive rate {fp_rate:.4%} ≤ {p_target:.2%}×1.10")
    else:
        print(f"FAILURE: false‑positive rate {fp_rate:.4%} exceeds allowed {p_target:.2%}×1.10")
