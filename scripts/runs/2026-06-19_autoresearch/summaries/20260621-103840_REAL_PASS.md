## Method (cited)

We will implement a tiny, self‑contained Python utility **`csv_stats.py`** that:

1. **Parses** a CSV string using the standard library `csv` module (no external dependencies).  
2. **Tracks** per‑column statistics while iterating rows:  
   * `count` – number of non‑empty values (used for mean).  
   * `sum` – cumulative sum of numeric values (float conversion).  
   * `min` – smallest numeric value seen.  
   * `max` – largest numeric value seen.  
3. **Computes** the mean after the final row as `sum / count` (skipping non‑numeric or empty cells).  
4. **Emits** a JSON document mapping each column header to an object `{ "min": …, "max": …, "mean": … }` via `json.dumps(..., sort_keys=True)`.

Key implementation details:

| Step | Code Sketch | Reason |
|------|-------------|--------|
| **Read CSV** | `reader = csv.DictReader(io.StringIO(csv_string))` | `DictReader` gives column names directly. |
| **Initialize per‑column accumulators** | For each field name create `stats[col] = {"count":0, "sum":0.0, "min":None, "max":None}` | Allows O(1) update per value. |
| **Update** | ```python\nvalue = row[col].strip()\nif value:\n    try:\n        num = float(value)\n    except ValueError:\n        continue  # ignore non‑numeric entries\n    stats[col][\"count\"] += 1\n    stats[col][\"sum\"]   += num\n    stats[col][\"min\"]   = num if stats[col][\"min\"] is None else min(stats[col][\"min\"], num)\n    stats[col][\"max\"]   = num if stats[col][\"max\"] is None else max(stats[col][\"max\"], num)\n``` | Handles missing/blank cells and non‑numeric strings gracefully. |

import csv,io,json,sys

def col_stats(s):
    r=csv.reader(io.StringIO(s))
    h=next(r)
    st={c:[0,0.0,None,None] for c in h}          # count,sum,min,max
    for row in r:
        for c,v in zip(h,row):
            if v:
                try: n=float(v)
                except: continue
                cnt,sm,mi,ma=st[c]
                cnt+=1; sm+=n
                mi=n if mi is None else (n if n<mi else mi)
                ma=n if ma is None else (n if n>ma else ma)
                st[c]=[cnt,sm,mi,ma]
    out={}
    for c in h:
        cnt,sm,mi,ma=st[c]
        out[c]={"max":ma,"mean":sm/cnt if cnt else None,"min":mi}
    return out

csv_txt="A,B\n1,3\n2,4\n3,5\n"
result=col_stats(csv_txt)
expected={"A":{"max":3.0,"mean":2.0,"min":1.0},"B":{"max":5.0,"mean":4.0,"min":3.0}}

if result==expected:
    print("SUCCESS:",json.dumps(result,sort_keys=True))
    sys.exit(0)
else:
    print("FAILURE:",json.dumps(result,sort_keys=True))
    sys.exit(1)
