## Method (cited)  
We will implement **two pure‑Python utilities** that are each *O(N)* in the number of leaf values:

| Utility | Description | Reference |
|---------|-------------|-----------|
| `flatten(d: dict, parent_key: str = "", sep: str = ".") -> dict` | Recursively traverses `d`. For each leaf value, builds a new key by concatenating the current `parent_key` (if any) with the leaf’s key using `sep`. Returns a flat dict whose keys use dotted notation. | Stack Overflow answer “Flatten nested dictionaries, compressing keys” [web:https://stackoverflow.com/questions/6027558/flatten-nested-dictionaries-compressing-keys] |
| `unflatten(d: dict, sep: str = ".") -> dict` | For every `<dotted>.key` entry, splits the key on `sep` and builds (or re‑uses) nested dictionaries accordingly. Leaf values are placed at the deepest level. | GeeksforGeeks “Convert Nested Dictionary into Flattened Dictionary” [web:https://www.geeksforgeeks.org/python/python-convert-nested-dictionary-into-flattened-dictionary/] |

Both functions will be **side‑effect‑free** and will raise a `ValueError` if a key collision would occur during unflattening (e.g., both `"a.b"` and `"a"` exist). The round‑trip property we need to verify is:

```python
orig = {"a": {"b": {"c": 1}, "d": 2}, "e": 3}
assert unflatten(flatten(orig)) == orig
```

The implementation will be placed in a module `dict_dot.py` so that it can be imported by downstream code without pulling in external dependencies.

import sys

def flatten(d, p=''):
    r={}
    for k,v in d.items():
        np=k if not p else p+'.'+k
        if isinstance(v,dict):
            r.update(flatten(v,np))
        else:
            r[np]=v
    return r

def unflatten(d):
    r={}
    for k,v in d.items():
        cur=r
        *heads,tail=k.split('.')
        for h in heads:
            cur=cur.setdefault(h,{})
        cur[tail]=v
    return r

sample={"x":{"y":{"z":"hello"}},'a':1}
if unflatten(flatten(sample))!=sample:
    print("FAILURE:")
    sys.exit(1)
print("SUCCESS:")
