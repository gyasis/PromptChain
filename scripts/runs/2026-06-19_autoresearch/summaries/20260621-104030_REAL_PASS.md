## Method (cited)  
The paragraph is first normalized to lower‑case and tokenized with a regular‑expression that extracts only word characters (`\w`).  
This removes punctuation and makes the count case‑insensitive – the same strategy used by popular online word‑frequency tools [1].  
The list of words is handed to `collections.Counter`, which efficiently tallies frequencies.  
`Counter.most_common(5)` then returns the top‑5 `(word, count)` pairs in descending order.  

```python
import re
from collections import Counter

def top5(paragraph: str) -> list[tuple[str, int]]:
    # 1. lower‑case
    # 2. extract words (ignore punctuation)
    words = re.findall(r"\b\w+\b", paragraph.lower())
    # 3. count
    return Counter(words).most_common(5)
```
