## Method (cited)  
Implement the LRU cache as a classic **hash‑map + doubly‑linked list** data structure:  

1. **Hash map (`dict`)** maps keys → node objects for O(1) lookup.  
2. **Doubly‑linked list** keeps nodes in recency order; the **head** is most‑recently used (MRU) and the **tail** is least‑recently used (LRU).  
3. **`get(key)`**  
   * If the key is absent → return `None`.  
   * If present → move the node to the head (MRU) and return its value.  
4. **`put(key, value)`**  
   * If key already exists → update its value and move node to head.  
   * Else create a new node, insert it at the head, add it to the map.  
   * If the cache size now exceeds the fixed capacity, **evict** the tail node (LRU) and delete its entry from the map.  

This algorithm guarantees O(1) time for both operations and matches the textbook description in the literature [web:https://www.geeksforgeeks.org/system-design/lru-cache-implementation/], [web:https://www.baeldung.com/java-lru-cache].  

The verification will use the canonical access pattern **A → B → C → A → D** with a capacity of **3**, expecting the eviction order **B** (first evicted) and then **C** when a further element is added.

import sys
from collections import OrderedDict

class LRU:
    def __init__(self, cap):
        self.cap, self.d, self.ev = cap, OrderedDict(), []
    def get(self, k):
        if k not in self.d: return None
        v = self.d.pop(k); self.d[k] = v; return v
    def put(self, k, v):
        if k in self.d: self.d.pop(k)
        self.d[k] = v
        if len(self.d) > self.cap:
            evk, _ = self.d.popitem(last=False)
            self.ev.append(evk)

c = LRU(3)
for k, v in [('A',1),('B',2),('C',3),('A',10),('D',4)]: c.put(k, v)
