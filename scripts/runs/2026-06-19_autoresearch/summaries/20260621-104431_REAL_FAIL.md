## Method (cited)  
We will implement a **single‑pass, O(n)** algorithm that keeps the **last** occurrence of each record identified by a user‑specified key (default `"id"`).  

1. **Reverse‑iterate** the input list.  
2. Insert each record into a temporary `dict` mapping `record[id_key] → record`. Because we are walking backwards, later (i.e., original‑later) records overwrite earlier ones, guaranteeing that the stored value is the *last* occurrence.  
3. After the loop, extract `temp.values()` and **reverse** the resulting sequence to restore the original order (minus the removed duplicates).  

Python 3.7+ guarantees insertion‑order preservation for dictionaries, so the final `list(dict.values())` already respects the order of insertion; the extra reversal step yields the original left‑to‑right ordering while keeping the last duplicate only.

**Why this works** – The approach mirrors the “group‑by‑and‑pick‑last” pattern described in StackOverflow [1] and GeeksforGeeks [2], but leverages the guaranteed order of dicts to avoid an explicit `reverse()` on the value list.
