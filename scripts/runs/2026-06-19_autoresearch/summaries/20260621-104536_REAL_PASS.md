## Method (cited)  

1. **Build adjacency map** – Iterate over the flat list of `(parent, child)` tuples and create a dictionary `children_of[parent] = [child, …]`.  
   *Reference*: Baeldung, “From Lists to Forests” – describes exactly this adjacency‑list construction [web:https://www.baeldung.com/cs/from-lists-to-forests].

2. **Identify roots** – A node that never appears as a child is a root. Collect all unique nodes, subtract the set of children, and the remainder are root identifiers.  
   *Reference*: StackOverflow answer “How to convert a flat parent‑child list …” – uses the same root‑discovery technique [web:https://stackoverflow.com/questions/79947460/how-to-convert-a-flat-parent-child-list-from-database-into-a-nested-tree-structu].

3. **Recursive tree builder** – Define a function `build_subtree(node, visited)` that:
   * Checks `node` is not already in `visited` (cycle detection).  
   * Marks `node` as visited.  
   * Recursively builds sub‑dicts for each child in `children_of.get(node, [])`.  
   * Returns `{node: {child1_subtree, child2_subtree, …}}` – where an empty dict denotes a leaf.  

4. **Forest assembly** – For each root, invoke `build_subtree(root, set())` and merge the resulting dictionaries into the final output.  

5. **Verification** – After construction, run two sanity checks:  
   * **Uniqueness** – Ensure every child appears under exactly one parent by counting occurrences across all sub‑trees.  
   * **Acyclicity** – If the recursion ever hits a node already in the `visited` set, raise `ValueError`.  

The algorithm works for a single‑root tree or a forest (multiple roots) and runs in **O(N)** time where *N* is the number of edges.

import sys

def edges_to_tree(es):
    chd, alln, chn = {}, set(), set()
    for p,c in es:
        chd.setdefault(p,[]).append(c)
        alln.update((p,c)); chn.add(c)
    roots = [n for n in alln if n not in chn]

    def dfs(n, stk):
        if n in stk: raise ValueError('cycle')
        stk.add(n)
        sub={}
        for c in chd.get(n,[]):
            sub.update(dfs(c, stk))
        stk.remove(n)
        return {n:sub}

    forest={}
    for r in roots:
        forest.update(dfs(r, set()))
    return forest
