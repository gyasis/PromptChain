## Chosen Approach  
Compute the key set of the first dictionary as the reference, then iterate over the remaining dictionaries comparing each’s `set(d.keys())` to the reference. For any dictionary where `reference - d.keys()` (missing keys) or `d.keys() - reference` (extra keys) is non‑empty, record the index and the differing keys so the caller can see exactly which entries mismatch. This simple set‑based check runs in O(N · K) time (N = number of dicts, K = average key count) and directly yields a clear mismatch report, as recommended in StackOverflow solutions for the same problem【web:https://stackoverflow.com/questions/10482439/make-sure-all-dicts-in-a-list-have-the-same-keys】【web:https://stackoverflow.com/questions/55458338/how-to-check-if-a-dictionary-has-exact-same-keys-in-a-list】.

## Method (cited)

1. **Choose a reference key set** –  
   Take the key set of the first dictionary in the list (`ref = set(dicts[0])`).  
   If the list is empty, return an empty report.

2. **Iterate and compare** –  
   For each subsequent dictionary `d` (with index `i`):
   * `missing = ref - d.keys()` – keys that are *absent* from `d`.
   * `extra   = d.keys() - ref`   – keys that are *present* in `d` but not in the reference.
   * If either set is non‑empty, record a mismatch entry  
     ```python
     {"index": i, "missing": sorted(missing), "extra": sorted(extra)}
     ```

3. **Collect and return** –  
   The function returns a list of all mismatch entries.  
   If the list is empty, every dictionary shares the same keys.

4. **Complexity** –  
   Each dictionary is inspected once; set operations are O(K) where *K* is the number of keys.  
   Overall time = O(N · K) and space = O(K) for the reference set plus O(M) for the report (M = # mismatches).

import sys

def validate_keys(dicts):
    if not dicts:
        return []
    ref = set(dicts[0])
    out = []
    for i, d in enumerate(dicts):
        miss = ref - d.keys()
        extra = d.keys() - ref
        if miss or extra:
            out.append({"index": i,
                        "missing": sorted(miss),
                        "extra": sorted(extra)})
    return out

# ---- inline test ----
sample = [
    {"a": 1, "b": 2},
    {"a": 3},                     # missing "b"
    {"a": 4, "b": 5, "c": 6}      # extra "c"
]

expected = [
    {"index": 1, "missing": ["b"], "extra": []},
    {"index": 2, "missing": [],  "extra": ["c"]}
]
