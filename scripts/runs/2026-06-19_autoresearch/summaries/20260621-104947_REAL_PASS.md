## Chosen Approach  
Use Welford’s one‑pass algorithm: keep a running count `n`, the current mean `μ`, and the aggregated squared deviation `M2`. For each new element `x` update with  

```python
n  += 1
delta   = x - μ
μ      += delta / n
delta2  = x - μ
M2     += delta * delta2
```

After processing the list, the variance is `M2/(n‑1)` for the unbiased sample estimate (or `M2/n` for the population variance). This method is numerically stable, requires O(1) memory, and works for any stream of numbers [web:https://en.wikipedia.org/wiki/Algorithms_for_calculating_variance] [web:https://nullbuffer.com/articles/welford_algorithm.html].

## Method (cited)

We will implement **Welford’s one‑pass algorithm** which keeps three scalar accumulators  

* `n` – number of observations processed so far  
* `mean` – current running mean (μ)  
* `M2` – sum of squared deviations from the current mean  

For each incoming datum `x` the update rules are  

```python
n    += 1
delta = x - mean
mean += delta / n
delta2 = x - mean
M2   += delta * delta2
```

After the whole list has been consumed  

* **Population variance**  = `M2 / n`  
* **Sample (unbiased) variance** = `M2 / (n‑1)`  (used when `n > 1`)  

The algorithm is numerically stable because it never forms large intermediate sums of squares; it works in O(1) memory and O(N) time, making it ideal for streaming or very large datasets [1][2].
