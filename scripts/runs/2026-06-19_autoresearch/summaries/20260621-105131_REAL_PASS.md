## Chosen Approach  
The most reliable solution is to iterate through the string once while maintaining a stack: push every opening bracket (`(`, `{`, `[`) onto the stack, and for each closing bracket (`)`, `}`, `]`) pop and verify the popped symbol matches the expected opening type. If the stack is empty at the end of the scan, the brackets are balanced; otherwise—or if a mismatch occurs early—the string is invalid. This linear‑time, O(n) stack algorithm is the standard method recommended for the “valid parentheses” problem [web:https://leetcode.com/problems/valid-parentheses/][web:https://www.geeksforgeeks.org/dsa/check-for-balanced-parentheses-in-an-expression/].

## Method (cited)  
The classic linear‑time algorithm uses a **stack** to match opening and closing brackets.  

1. Iterate over each character `c` in the input string.  
2. If `c` is an opening bracket (`(`, `[`, `{`), push it onto the stack.  
3. If `c` is a closing bracket, pop the top of the stack; the popped symbol must be the matching opening type (`)` ↔ `(`, `]` ↔ `[`, `}` ↔ `{`).  
4. Any mismatch or attempt to pop from an empty stack means the string is **invalid**.  
5. After the scan, the string is **balanced** only if the stack is empty.  

This approach runs in **O(n)** time and **O(n)** auxiliary space in the worst case, where *n* is the length of the string. It is the standard solution described in many references, e.g., GeeksforGeeks [web:https://www.geeksforgeeks.org/dsa/check-for-balanced-parentheses-in-an-expression/] and LeetCode [web:https://leetcode.com/problems/valid-parentheses/].

def is_balanced(s: str) -> bool:
    pairs = {')': '(', ']': '[', '}': '{'}
    stack = []
    for ch in s:
        if ch in pairs.values():          # opening
            stack.append(ch)
