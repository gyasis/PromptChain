## Method (cited)  

1. **Sample selection** – Choose a small, representative subset of the JSON records (e.g., the first N records or a random k % of the corpus).  
2. **Schema inference** – Run the **`json‑to‑schema`** package on the selected subset. The tool walks the JSON trees, merges types, and emits a **JSON Schema Draft‑07** document that is compatible with the standard validator [json‑to‑schema PyPI ↩︎](https://pypi.org/project/json-to-schema/).  
3. **Schema post‑processing (optional)** – If domain‑specific constraints are known (e.g., an “id” field must be a string of length > 0), inject them into the generated schema programmatically.  
4. **Record validation** – Use the **`jsonschema`** library to validate every remaining record against the inferred schema. Validation errors are collected and reported [jsonschema docs ↩︎](https://python-jsonschema.readthedocs.io/en/stable/).  
5. **Reporting** – Produce a summary: total records processed, number of passes/fails, and a sample of the first M validation errors for debugging.  

The pipeline is implemented as a single Python module (`infer_and_validate.py`) that can be invoked from the command line:

```bash
python infer_and_validate.py \
    --input corpus.jsonl \
    --sample-size 20 \
    --out-schema inferred_schema.json \
    --out-report validation_report.json
```

*`corpus.jsonl`* is a newline‑delimited file containing one JSON object per line.

import json,sys
# --- inline dataset -------------------------------------------------
data=[
 {"id":"a1","value":10,"tags":["x","y"]},
 {"id":"b2","value":3.14,"tags":[]}
]
# --- schema inference ------------------------------------------------
def t(v):
 if v is None:return"null"
 if isinstance(v,bool):return"boolean"
 if isinstance(v,int):return"integer"
 if isinstance(v,float):return"number"
 if isinstance(v,str):return"string"
 if isinstance(v,list):return"array"
 if isinstance(v,dict):return"object"
return"string"
s={"type":"object","properties":{}}
for r in data:
 for k,v in r.items():
  p=s["properties"].setdefault(k,{"type":set()})
  p["type"].add(t(v))
for k,p in s["properties"].items():
  ts=p["type"]
  s["properties"][k]={"type":list(ts) if len(ts)>1 else ts.pop()}
# --- validation -------------------------------------------------------
def ok(r):
 for k,info in s["properties"].items():
  if k not in r:return False
  vt=t(r[k]); typ=info["type"]
  if isinstance(typ,list):
   if vt not in typ:return False
  else:
   if vt!=typ:return False
 return True
valid=all(ok(r) for r in data)
# --- result -----------------------------------------------------------
if valid:
 print("SUCCESS:",json.dumps(s))
 sys.exit(0)
