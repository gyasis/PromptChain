## Method (cited)  
We will implement a classic **pointer‑based prefix trie** (also called a *Trie* or *Prefix Tree*). Each node holds:

* a **dictionary** (`children`) mapping a single character → child node  
* a **boolean flag** (`is_word`) that marks the end of a valid word  

The public API will expose two operations required by the brief:

| Operation | Description | Complexity |
|-----------|-------------|------------|
| `insert(word: str) -> None` | Walk the characters of `word`; create missing child nodes; set `is_word = True` on the terminal node. | **O(L)** where *L* = `len(word)` |
| `startsWith(prefix: str) -> bool` | Walk the characters of `prefix`; return `True` only if the full path exists (regardless of `is_word`). | **O(L)** |

The design follows the canonical description of tries in the literature [corpus] and the LeetCode reference implementation [web:https://leetcode.com/problems/implement-trie-prefix-tree/].  

Implementation steps  

1. **File layout** – create `trie.py` containing the `TrieNode` and `Trie` classes.

3. **`Trie.insert`** – iterate over characters, using `setdefault` to create child nodes on‑the‑fly, then mark the final node.  
4. **`Trie.startsWith`** – identical walk but stops early if a character is missing; returns the boolean result of the walk.

import sys

class Trie:
    __slots__ = ('ch', 'end')
    def __init__(self):
        self.ch = {}
        self.end = False
    def insert(self, w):
        n = self
        for c in w:
            n = n.ch.setdefault(c, Trie())
        n.end = True
    def startsWith(self, p):
        n = self
        for c in p:
            if c not in n.ch:
                return False
            n = n.ch[c]
        return True

t = Trie()
for w in ("ace", "ant", "cat", "pen", "pet"):
    t.insert(w)

ok = t.startsWith("a") and t.startsWith("pe") and not t.startsWith("ba")
print("SUCCESS:" if ok else "FAILURE:")
if not ok:
    sys.exit(1)
