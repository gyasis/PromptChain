## Chosen Approach  
The most effective solution is to employ the open‑source **csv‑schema‑inference** tool, which reads a CSV, examines a configurable sample of rows, and automatically classifies each column as `INTEGER`, `FLOAT`, `DATE` (using common date patterns) or `STRING`. It then emits a concise schema report (e.g., JSON or plain‑text) that lists each column name together with its inferred type, making the result immediately usable for downstream processing. ## Method (cited)

1. **Read a CSV sample** – Use Python’s built‑in `csv` module (or `pandas.read_csv` with `nrows=`) to load the first *N* rows (default = 1 000) into memory.  
2. **Detect candidate types per column** – For each cell try to cast in the following order, stopping at the first successful conversion:  
   * **int** – `int(value)` with strict “no‑decimal‑point” validation.  
   * **float** – `float(value)` where `int` failed and the string matches `^[+-]?(\d*\.\d+|\d+\.\d*)([eE][+-]?\d+)?$`.  
   * **date** – Try to parse with a list of common ISO‑like and US‑style formats using `datetime.strptime`. The formats list is taken from the “csv‑schema‑inference” project [1].  
   * **str** – Fallback for any value that cannot be parsed as the above.  

   While scanning the sample we keep a **type‑set** per column (e.g., `{int, float}`) and promote the column type when a more generic type is required (int → float → date → str). This mirrors the heuristic described in the “csv‑schema‑inference” repository [1] and the Spark `inferSchema` behaviour [2].

3. **Finalize column types** – After examining the sample, assign each column the *most specific* type that survived all rows:
   * If only `int` appears → `int`  
   * If `int` + `float` → `float`  
   * If any `date` appears (and no `str`) → `date`  
   * If any `str` appears → `str`

4. **Emit a schema report** – Produce a JSON document (pretty‑printed) of the form  

```json

}
```

```python
# ---------- Type inference helpers ----------
date_formats = [
    "%Y-%m-%d", "%Y/%m/%d", "%d-%m-%Y", "%m/%d/%Y",
    "%Y.%m.%d", "%d.%m.%Y", "%Y%m%d", "%d%m%Y"
]

def infer_cell(v: str):
    """Return one of 'int','float','date','str' for a non‑empty cell."""
    # int (no decimal point)
    try:
        if v.strip().isdigit() or (v[0] in '+-' and v[1:].isdigit()):
            int(v)
            return 'int'
    except Exception:
        pass
    # float (contains a dot or exponent)
    try:
        if any(c in v for c in ".eE"):
            float(v)
            return 'float'
    except Exception:
        pass
    # date
    for fmt in date_formats:
        try:
            datetime.datetime.strptime(v, fmt)
            return 'date'
        except Exception:
            continue
    # fallback
    return 'str'

# ---------- Schema inference ----------
def infer_schema(csv_text: str):
    f = io.StringIO(csv_text)
    reader = csv.reader(f)
    header = next(reader)
    # flags per column
    flags = [{ 'int': False, 'float': False, 'date': False, 'str': False } for _ in header]

    for row in reader:
        for i, cell in enumerate(row):
            cell = cell.strip()
            if not cell:                     # ignore empty cells
                continue
            typ = infer_cell(cell)
            flags[i][typ] = True

    # decide final type per column (priority: str > date > float > int)
    result = []
    for name, fdict in zip(header, flags):
        if fdict['str']:
            typ = 'str'
        elif fdict['date']:
            typ = 'date'
        elif fdict['float']:
            typ = 'float'
        elif fdict['int']:
            typ = 'int'
        else:               # column entirely empty
            typ = 'str'
        result.append({"name": name, "type": typ})
    return {"columns": result}
```
