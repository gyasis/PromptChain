## Method (cited)  
Implement **Algorithm R** (the classic reservoir sampler) as described in the original reservoir‑sampling paper and Wikipedia entry【web:https://en.wikipedia.org/wiki/Reservoir_sampling】.  

1. **Initialize** a list `reservoir` with the first `k` items of the incoming stream.  
2. For each subsequent item `item` arriving at 0‑based index `i` (where `i ≥ k`):  
   * Draw a random integer `j = random.randint(0, i)`.  
   * If `j < k`, replace `reservoir[j]` with `item`.  
3. After the stream ends, `reservoir` contains exactly `k` items, each item of the (unknown‑size) stream having equal probability `k / n` of being selected, where `n` is the total number of items processed.  

The implementation will be a pure‑Python function:

```python
from __future__ import annotations
import random
from typing import Iterable, List, TypeVar

T = TypeVar("T")

def reservoir_sample(stream: Iterable[T], k: int) -> List[T]:
    """Return a uniform random sample of size k from an arbitrary iterable `stream`.

    Raises:
        ValueError: if k is negative or if the stream yields fewer than k items.
    """
    if k < 0:
        raise ValueError("k must be non‑negative")
    it = iter(stream)

    # 1️⃣ Fill the reservoir with the first k elements
    reservoir: List[T] = []
    for _ in range(k):
        try:
            reservoir.append(next(it))
        except StopIteration:
            raise ValueError("stream contains fewer than k items") from None

    # 2️⃣ Process the rest of the stream in a single pass
    for i, item in enumerate(it, start=k):
        j = random.randint(0, i)
        if j < k:
            reservoir[j] = item

    # 3️⃣ At this point len(reservoir) == k by construction
    return reservoir
```

The function is deterministic in its *interface* (always returns a list of length `k`) but nondeterministic in the actual sampled values, as required by the algorithm.
