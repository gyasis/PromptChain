## Chosen Approach  
Use DuckDB’s `read_csv_auto` function to create a table directly from the CSV file; the engine automatically infers column types, eliminating the need for manual schema definition. After loading, verify the import by running a simple `SELECT COUNT(*)` against the new table. This single‑line import plus verification is concise, fast, and works entirely in‑process without external tooling.  

**Evidence:** The DuckDB demo shows `CREATE TABLE p AS SELECT * FROM read_csv_auto('points.csv');` followed by a row‑count query [corpus]; similar CSV‑to‑SQLite loaders exist (e.g., csvlite) but require explicit insertion logic, whereas DuckDB handles inference and loading in one step [web:url].

## Plan

```
## Method (cited)

1. **Read the CSV** – Use Python’s built‑in `csv` module to stream the file line‑by‑line, avoiding loading the whole file into memory.  
2. **Infer column types** – Scan the first *N* rows (default = 100, configurable) and for each column keep a set of candidate types (`INTEGER`, `REAL`, `TEXT`).  
   * If every observed value parses as an int → `INTEGER`.  
   * Else if every observed value parses as a float → `REAL`.  
   * Otherwise → `TEXT`.  
   This mirrors DuckDB’s `read_csv_auto` behaviour, which automatically chooses the most specific type that fits the data【corpus】.  
3. **Create the SQLite table** – Build a `CREATE TABLE` statement from the inferred schema and execute it with the standard `sqlite3` driver.  
4. **Insert rows** – Re‑open the CSV, convert each field to the inferred Python type (`int`, `float`, or `str`), and use a parameterised `INSERT INTO … VALUES (…)` statement to load data in batches of 5 000 rows (speed‑vs‑memory trade‑off).  
5. **Verify row count** – After loading, run `SELECT COUNT(*) FROM <table>` and compare the result to the number of data rows read from the CSV. If they differ, raise an exception; otherwise the load is considered successful.

All steps are performed in‑process, require only the Python standard library, and therefore satisfy the “no external constraints” requirement.

```python
import csv, sqlite3, sys, io

csv_data = """id,name,age,score
1,Alice,30,85.5
2,Bob,25,90
3,Charlie,,78
"""

# parse CSV
rows = list(csv.reader(io.StringIO(csv_data)))
hdr, data = rows[0], rows[1:]

# type inference
typ = [int] * len(hdr)
for r in data:
    for i, v in enumerate(r):
        if v == '':
            continue
        if typ[i] is int:
            try: int(v); continue
            except: pass
            try: float(v); typ[i] = float; continue
            except: pass
            typ[i] = str
        elif typ[i] is float:
            try: float(v); continue
            except: typ[i] = str

# create SQLite table
c = sqlite3.connect(":memory:").cursor()
cols = ", ".join(f'"{n}" {"INTEGER" if t is int else "REAL" if t is float else "TEXT"}'
                 for n, t in zip(hdr, typ))
c.execute(f'CREATE TABLE t({cols})')

# insert rows
ph = ",".join("?" for _ in hdr)
ins = f'INSERT INTO t VALUES({ph})'
for r in data:
    conv = [None if v == '' else int(v) if t is int else float(v) if t is float else v
            for v, t in zip(r, typ)]
    c.execute(ins, conv)
c.connection.commit()

# verification
cnt = c.execute('SELECT COUNT(*) FROM t').fetchone()[0]
if cnt == len(data):
    print(f"SUCCESS: {cnt} rows loaded")
    sys.exit(0)
else:
    print(f"FAILURE: expected {len(data)} rows, got {cnt}")
    sys.exit(1)
