## Method (cited)

The algorithm processes the CSV in a streaming fashion to keep memory usage low:

1. Open the CSV file with `csv.reader` (or `csv.DictReader` if headers are needed).  
2. For each row, concatenate the canonical string representation of its fields (e.g., `",".join(row)`).  
3. Compute a deterministic hash of that string using a fast, collision‑resistant function such as **SHA‑256** from the standard library `hashlib`.  
4. Store the hash in an in‑memory dictionary `hash_counts` that maps *hash → occurrence count*.  
5. Track the total number of rows processed (`total_rows`).  
6. After the file is exhausted, compute the number of *duplicate rows* as the count of hash entries whose value > 1.  
7. Report the **duplicate ratio** as  

\[
\text{duplicate ratio} = \frac{\text{# rows with count > 1}}{\text{total rows}}
\]

This approach follows classic hash‑based duplicate detection described in the literature and community examples [corpus]​, and matches the implementation strategy used by open‑source tools such as **Data‑Shadow‑Slayer** [github]​ and the memory‑efficient examples on w3reference [web]​.

### Why SHA‑256?

- Deterministic across platforms.  
- Low probability of collisions for typical CSV sizes.  
- Available in the Python standard library (no external dependencies).

import csv,hashlib,io,sys
s="""a,b,c
1,2,3
4,5,6
1,2,3
7,8,9
"""
t=0
d={}
for r in csv.reader(io.StringIO(s)):
    t+=1
    h=hashlib.sha256(','.join(r).encode()).hexdigest()
    d[h]=d.get(h,0)+1
dup=sum(1 for v in d.values() if v>1)
ratio=dup/t
if abs(ratio-0.2)<1e-12:
    print("SUCCESS:",ratio)

    print("FAILURE:",ratio)
