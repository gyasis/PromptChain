## Method (cited)

We will implement a **streaming two‑pointer merge** that consumes two already‑sorted record iterators (e.g., file streams, database cursors, generator objects) without loading either **fully** into memory.

1. **Open each source as an iterator** (`it1`, `it2`).  
2. **Peek** the next record from each side (`next1`, `next2`).  
3. **Compare keys** (`next1.key` vs `next2.key`).  
   * Emit the record with the smaller (or equal) key.  
   * Advance the iterator that supplied the emitted record.  
   * If the keys are equal, emit a single record (or both, depending on the merge policy) and advance **both** iterators.  
4. **Ordering verification** – keep `last_key` (initially `None`). After emitting a record, assert `last_key is None or emitted.key >= last_key`; update `last_key`. If the assertion fails, raise `RuntimeError`.  
5. Continue until both iterators are exhausted.

The algorithm consumes **O(1) additional memory** (only the two “peek” records and a scalar for `last_key`) and runs in **O(n + m)** time where *n* and *m* are the lengths of the input streams.

*Evidence*:  
- The two‑pointer technique is the classic merge step of merge‑sort [web:https://en.wikipedia.org/wiki/Merge_sort].  
- A Stack‑Overflow discussion demonstrates the same logic for streaming key/value lists [web:https://stackoverflow.com/questions/37768906/efficiently-merging-and-re-sorting-sorted-lists].

The implementation will be provided as a single Python function `stream_merge(it1, it2, key=lambda r: r[0]) → iterator` that yields merged records and validates ordering on‑the‑fly.

def stream_merge(a, b, key=lambda r: r[0]):
    a, b = iter(a), iter(b)
    try: x = next(a)
    except StopIteration: x = None
    try: y = next(b)
    except StopIteration: y = None
    last = None
    while x is not None or y is not None:
        if y is None or (x is not None and key(x) < key(y)):
            cur, nxt = x, lambda: next(a)
            try: x = nxt()
            except StopIteration: x = None
        elif x is None or key(y) < key(x):
            cur, nxt = y, lambda: next(b)
            try: y = nxt()
            except StopIteration: y = None
        else:                                    # equal keys → keep first, drop second

            except StopIteration: x = None
            try: y = nxt2()
            except StopIteration: y = None

        last = key(cur)
