## Method (cited)  

1. **Determine bin parameters** – Choose a fixed number of bins **B** (or a fixed bin‐width **w**) based on the data range \([x_{\min},x_{\max}]\).  
   * For a fixed‑width approach we compute  

   \[
   w = \frac{x_{\max}-x_{\min}}{B}
   \]

   where \(B\) can be derived from a rule of thumb such as Sturges’ formula or the Freedman‑Diaconis rule [web:https://stats.stackexchange.com/questions/798].  

2. **Create storage** – Allocate an integer array `bins[0..B‑1]` initialised to zero and a running counter `total = 0`.  

3. **Stream processing (single‑pass)** – For each incoming numeric value `x`:
   * Clamp to the range: if `x < x_min` → assign to underflow bin (index 0); if `x > x_max` → assign to overflow bin (index B‑1).  
   * Compute the bin index  

   ```python
   idx = int((x - x_min) // w)
   idx = max(0, min(B-1, idx))     # safety clamp
   ```  

   * Increment `bins[idx] += 1` and `total += 1`.  

4. **Verification** – After the stream ends, assert  

   \[
   \sum_{i=0}^{B-1} bins[i] = total = N
   \]

   If the equality fails, raise an exception – this guarantees that every element was counted exactly once.

5. **Optional post‑processing** – Convert raw counts to densities, cumulative counts, etc., but the verification step must run **before** any transformation.
