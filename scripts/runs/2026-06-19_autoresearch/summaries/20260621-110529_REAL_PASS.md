## Method (cited)  
We will implement a **deterministic Kahn‑style BFS topological sort** that guarantees a stable ordering for nodes that have no dependency ordering constraints.  

1. **Build graph structures**  
   * Compute in‑degree for each node.  
   * Build an adjacency list from the supplied `(node, deps)` tuples.  

2. **Deterministic zero‑in‑degree selection**  
   * All nodes with in‑degree 0 are kept in a **list that respects the original input order** (i.e., stable).  
   * Each iteration pops the first element from this list, appends it to the result, and decrements the in‑degree of its successors.  
   * When a successor’s in‑degree drops to 0 it is appended to the list.  

   This approach mirrors the “stable Kahn’s algorithm” described in the literature [GeeksforGeeks – Topological Sorting][web:https://www.geeksforgeeks.org/dsa/topological-sorting/]; the same technique is used to obtain deterministic output by preserving the initial ordering [TechnetExperts – Ensuring Stable Topological Sort Results in Python][web:https://www.technetexperts.com/python-topological-sort-stability/].

3. **Verification of the produced order**  
   * After a candidate ordering is produced, iterate over the list and keep a set of already‑seen nodes.  
   * For each node, ensure that **all of its declared dependencies appear in the seen set**.  
   * If any dependency is missing, the ordering is invalid and the DAG is either malformed or contains a cycle.  

   This O(V + E) check provides a cheap correctness guard.

4. **Error handling**  
   * If at any point there are still nodes remaining but the zero‑in‑degree list is empty, the input graph contains a cycle; raise `ValueError("Cyclic dependency detected")`.  

The implementation will be pure‑Python, using only the standard library (`typing`, `collections`).

import sys

# tiny inline DAG: each tuple is (node, [its dependencies])
dag = [('a', []), ('b', ['a']), ('c', ['b'])]

# build adjacency list and indegree map
adj = {}
indeg = {}
for n, ds in dag:
    adj.setdefault(n, [])
    indeg.setdefault(n, 0)
for n, ds in dag:
    for d in ds:
        adj.setdefault(d, []).append(n)
        indeg[n] = indeg.get(n, 0) + 1
        indeg.setdefault(d, 0)

# Kahn's algorithm with a stable zero‑indegree queue (preserves input order)
zero = [n for n, _ in dag if indeg[n] == 0]
res = []
while zero:
    v = zero.pop(0)          # stable pop
    res.append(v)
    for nb in adj[v]:
        indeg[nb] -= 1
        if indeg[nb] == 0:
            zero.append(nb)   # preserve discovery order

# cycle detection
if len(res) != len(indeg):
    print('FAILURE: cycle detected')
    sys.exit(1)

# verify that every dependency appears earlier in the result
pos = {v: i for i, v in enumerate(res)}
for n, ds in dag:
    for d in ds:
        if pos[d] > pos[n]:
            print('FAILURE: invalid order')
            sys.exit(1)

print('SUCCESS:', res)
