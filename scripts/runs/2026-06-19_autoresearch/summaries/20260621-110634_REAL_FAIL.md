## Chosen Approach  
Maintain a Count‑Min Sketch to receive the stream and produce low‑error frequency estimates for every item, and keep a min‑heap (size K) of the current best candidates. After each update, query the sketch for the item’s estimated count; if it exceeds the smallest count in the heap, replace that entry and update a small hash‑map that stores the exact counts for the K items in the heap. This combination gives sub‑linear memory for the whole stream while guaranteeing fast O(1) updates and O(log K) top‑K maintenance.

## Method (cited)  

The algorithm follows the classic **Count‑Min Sketch (CMS)** for sub‑linear frequency estimation combined with a **size‑K min‑heap** to maintain the current top‑K heavy‑hitters. The workflow is:  

1. **Initialize** a CMS with width *w* and depth *d* (error ε ≈ 2/eᵈ, failure probability δ ≈ e⁻ᵈ) and an empty min‑heap of capacity *K*.  
2. **For each streamed item** `x`:  
   * Update the CMS counters: `cms.update(x, 1)`.  
   * Query the estimated count `ĉ = cms.query(x)`.  
   * If `x` is already in the heap, update its stored exact count to `ĉ` and re‑heapify.  
   * Else, if the heap is not full, push `(ĉ, x)` onto the heap and store the exact count in a side‑hash‑map `top_counts[x] = ĉ`.  
   * Otherwise, compare `ĉ` to the smallest count in the heap (`heap[0][0]`). If `ĉ` > `heap[0][0]`, pop the min entry, delete its key from `top_counts`, and push `(ĉ, x)` onto the heap, updating `top_counts`.  
3. **Report** the heap contents sorted by decreasing estimated count as the current top‑K list.  

The method is described in several system‑design references:

import sys, hashlib, heapq

class CMS:
    def __init__(self,w=1000,d=3):
        self.w,self.d=w,d
        self.t=[[0]*w for _ in range(d)]
        self.s=[bytes([i]) for i in range(d)]
    def _h(self,i,x):
        return int(hashlib.blake2b(str(x).encode(),person=self.s[i],digest_size=4).hex(),16)%self.w
    def add(self,x):
        for i in range(self.d):
            self.t[i][self._h(i,x)]+=1
    def est(self,x):
        return min(self.t[i][self._h(i,x)] for i in range(self.d))

def topk_stream(k,stream):
    cms=CMS()
    heap=[]           # (est,item)
    pos={}            # item->est (current best)
    for x in stream:
        cms.add(x)
        e=cms.est(x)
        if x in pos:
            pos[x]=e
            heapq.heappush(heap,(e,x))
        elif len(pos)<k:
            pos[x]=e
            heapq.heappush(heap,(e,x))
        else:
            # discard stale minima
            while heap and pos.get(heap[0][1])!=heap[0][0]:
                heapq.heappop(heap)
            if heap and e>heap[0][0]:
                _,old=heapq.heappop(heap)
                del pos[old]
                pos[x]=e
                heapq.heappush(heap,(e,x))
    # clean heap of stale entries
    while heap and pos.get(heap[0][1])!=heap[0][0]:
        heapq.heappop(heap)
    return [item for _,item in sorted(((v,k) for k,v in pos.items()),reverse=True)]
