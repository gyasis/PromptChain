## Method (cited)

1. **Data structure** – Use a fixed‑size bit array (`bytearray` for speed) of length *m* bits.  
2. **Hash functions** – Derive *k* independent hashes from a single strong 64‑bit hash (e.g., `mmh3.hash64`). For element `x` we compute  

   ```
   h0 = mmh3.hash64(str(x))[0]
   for i in range(k):
       position = (h0 + i * delta) % m                # delta = another hash or a constant
   ```
   This “double‑hashing” technique is proven to produce *k* uniformly distributed indices while only hashing once [Kirsch & Mitzenmacher, 2006].

3. **Parameter selection** –  
   * Desired false‑positive probability **p** (user‑supplied).  
   * Expected number of inserted items **n**.  

   Classic Bloom‑filter formulas [Broder & Mitzenmacher, 2004] give  

   ```
   m = ceil(-(n * ln(p)) / (ln(2) ** 2))
   k = round((m / n) * ln(2))
   ```

4. **Insert** – For each element, compute its *k* positions and set the corresponding bits to 1.  

5. **Query** – Compute the same *k* positions; return **True** iff all bits are 1, otherwise **False**.  

6. **Measurement** –  
   * Insert a known set `S` of size *n*.  
   * Generate a disjoint test set `T` (e.g., same size, different random strings).  
   * Query each element of `T`; count positives → **FP** (false positives).  
   * Observed false‑positive rate = `FP / |T|`.  

   Compare this empirical rate with the target **p**; it should be ≤ *p* + ε (ε = 0.02 is a reasonable statistical tolerance for small samples).

All steps are implemented in pure Python (standard library + `mmh3` for hashing).

import sys, math, random, hashlib

# ----- configuration -----
n = 30                     # number of inserted items
p_target = 0.05           # desired false‑positive probability
epsilon = 0.02            # tolerance
test_size = 2000          # number of queries on a disjoint set

# ----- optimal parameters -----
m = math.ceil(-(n * math.log(p_target)) / (math.log(2) ** 2))   # bits
k = max(1, round((m / n) * math.log(2)))                       # hash functions
bits = bytearray((m + 7) // 8)

def _set(i):
    bits[i // 8] |= 1 << (i % 8)

def _get(i):
    return (bits[i // 8] >> (i % 8)) & 1

def _pos(item):
    d = hashlib.sha256(item.encode()).digest()
    h1 = int.from_bytes(d[:8], 'big')
    h2 = int.from_bytes(d[8:16], 'big') or 1   # avoid zero step
    for j in range(k):
        yield (h1 + j * h2) % m

def add(item):
    for p in _pos(item):
        _set(p)

def query(item):
    return all(_get(p) for p in _pos(item))

# ----- create sets -----
random.seed(0)
insert_set = {f'i{i}' for i in range(n)}
test_set   = {f't{i}' for i in range(test_size)} - insert_set   # disjoint

# ----- populate filter -----
for x in insert_set:
    add(x)

# ----- evaluate false positives -----
fp = sum(1 for x in test_set if query(x))
observed = fp / test_size

print(f'params: m={m}, k={k}, target={p_target:.3f}, observed={observed:.3f}')
if observed <= p_target + epsilon:
    print('SUCCESS: false‑positive rate within tolerance')
    sys.exit(0)
else:
    print('FAILURE: false‑positive rate too high')
    sys.exit(1)
