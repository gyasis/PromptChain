## Method (cited)

Implement the classic **P² (P‑square) algorithm** [[1]](https://aakinshin.net/posts/post-mp2-quantile-estimator/) to maintain a *streaming* estimate of the median (0.5‑quantile).  

The algorithm keeps **five markers**:

| Marker | Quantile | Description |
|-------|----------|-------------|
| m₀ | 0 | minimum |
| m₁ | 0.25 | first quartile |
| m₂ | 0.5 | median (the target) |
| m₃ | 0.75 | third quartile |
| m₄ | 1 | maximum |

Each marker stores **height** (the data value) and **position** (the integer rank it currently occupies).  
For each incoming value `x`:

1. **Update heights** – insert `x` into the appropriate interval between markers and adjust the heights of the extreme markers (`m₀` and `m₄`) if `x` is a new min/max.  
2. **Desired positions** – the algorithm defines target positions `np[i] = n * q[i] + 1` where `q[i]` is the quantile of marker *i* and `n` is the total number of samples seen.  
3. **Increment positions** – for markers to the right of the insertion point, increment their actual positions `p[i]`.  
4. **Adjustment step** – for each interior marker `i = 1..3` compute `d = np[i] - p[i]`.  
   *If* `|d| ≥ 1` **and** the marker is not at a boundary, move the marker one step toward its target using the **parabolic interpolation** formula (the original P² update).  
   If the parabolic estimate would violate monotonicity, fall back to a **linear** adjustment.  

The median estimate is always `height[2]`.  
The algorithm requires **O(1)** memory (five markers) and **O(1)** amortised time per update, satisfying the “do not store all values” constraint.

import sys

class P2Median:
    def __init__(self):
        self.n = 0
        self.q = [0.0, 0.25, 0.5, 0.75, 1.0]      # desired quantiles
        self.h = []                               # marker heights
        self.p = []                               # actual positions
        self.np = []                              # desired positions

    def add(self, x):
        if self.n < 5:                # bootstrap phase
            self.h.append(x)
            self.n += 1
            if self.n == 5:
                self.h.sort()
                self.p = [1, 2, 3, 4, 5]
                self.np = [1 + qi * (self.n - 1) for qi in self.q]
            return

        # locate bucket
        if x < self.h[0]:
            self.h[0] = x
            k = 0
        elif x >= self.h[-1]:
            self.h[-1] = x
            k = 3
        else:
            for i in range(4):
                if self.h[i] <= x < self.h[i+1]:
                    k = i
                    break

        # increment positions right of insertion point
        for i in range(k+1, 5):
            self.p[i] += 1

        self.n += 1
        for i, qi in enumerate(self.q):
            self.np[i] = 1 + qi * (self.n - 1)

        # adjust interior markers
        for i in range(1, 4):
            d = self.np[i] - self.p[i]
            if (d >= 1 and self.p[i+1] - self.p[i] > 1) or (d <= -1 and self.p[i] - self.p[i-1] > 1):
                d_sign = 1 if d > 0 else -1
                self._move(i, d_sign)

    def _move(self, i, d):
        p0, p1, p2 = self.p[i-1], self.p[i], self.p[i+1]
        h0, h1, h2 = self.h[i-1], self.h[i], self.h[i+1]

        # parabolic estimate
        delta = d / (p2 - p0) * ((p1 - p0 + d) * (h2 - h1) / (p2 - p1) +

            self.h[i] = new_h
            self.p[i] += d

            self.h[i] += d * (self.h[i+d] - self.h[i]) / (self.p[i+d] - self.p[i])
