Implement a **MinHash + LSH pipeline with the Python `datasketch` library**:  

1. **Pre‑process each CSV row** (lower‑case, strip punctuation, optionally tokenize on whitespace, and concatenate the fields into a single string).  
2. **Create a MinHash signature** for every row using a moderate number of permutations (e.g., `num_perm=128`) to approximate Jaccard similarity of the token sets.  
3. **Insert the signatures into a Locality‑Sensitive Hash (LSH) index** (`datasketch.MinHashLSH`) with a similarity threshold tuned to the desired “near‑duplicate” tolerance (e.g., 0.8).  
4. **Query the LSH** to retrieve candidate duplicate groups, merge overlapping groups, and keep a single representative row per group.  
5. **Report the deduplication ratio** as `(original_row_count − unique_row_count) / original_row_count`.  

This approach directly leverages a proven MinHash‑LSH workflow for large, noisy text collections and provides an easy way to compute the deduplication metric.

## Method (cited)

1. **Load the CSV** – use `pandas.read_csv` with `error_bad_lines=False` (or `on_bad_lines='skip'` in newer pandas) to tolerate malformed rows.  

2. **Normalize each row** – for every record:  
   * Concatenate all fields into a single string.  
   * Lower‑case, strip surrounding whitespace, remove punctuation (`string.punctuation`).  
   * Tokenize on whitespace (`str.split()`).  
   The resulting list of tokens is the *shingle set* for that row.  

3. **Create MinHash signatures** – for each token set, build a `datasketch.MinHash` object with a fixed number of permutations (e.g., `num_perm=128`).  
   ```python
   from datasketch import MinHash
   m = MinHash(num_perm=128)
   for token in token_set:
       m.update(token.encode('utf8'))
   ```
   This approximates the Jaccard similarity of the token sets 【1】.  

4. **Insert into an LSH index** – instantiate `datasketch.MinHashLSH` with a similarity threshold that defines “near‑duplicate” (e.g., `threshold=0.8`).  
   ```python
   from datasketch import MinHashLSH
   lsh = MinHashLSH(threshold=0.8, num_perm=128)
   for i, mh in enumerate(minhashes):
       lsh.insert(f"row_{i}", mh)
   ```
   The LSH groups together signatures whose estimated Jaccard similarity exceeds the threshold 【2】.  

5. **Retrieve candidate groups** – for each row, query the LSH to obtain its neighbour IDs. Build an undirected graph where rows are nodes and an edge exists if they appear in each other’s query result. Connected components of this graph correspond to duplicate clusters.  

6. **Deduplicate** – for each component keep a single representative row (e.g., the first encountered) and discard the rest.  

7. **Report deduplication ratio**  
   \[
   \text{dedup\_ratio} = \frac{N_{\text{original}} - N_{\text{unique}}}{N_{\text{original}}}
   \]  
   where `N_original` is the total row count before deduplication and `N_unique` is the count after keeping one per component.

import csv, string, random, sys
from io import StringIO

# ── tiny messy CSV ────────────────────────────────────────────────────────
csv_data = """id,desc
1,Apple orange banana
2,apple orange banana!
3,Apple, orange; banana?
4,pear grape
5,pear  grape
"""

# ── read & normalize rows ─────────────────────────────────────────────────
rows = []
for r in csv.reader(StringIO(csv_data)):
    if rows or r[0] != 'id':          # skip header
        txt = ' '.join(r[1:]).lower()
        txt = txt.translate(str.maketrans('', '', string.punctuation))
        rows.append(txt.split())

# ── MinHash signature (pure stdlib) ────────────────────────────────────────
prime = (1 << 61) - 1
num_perm = 32
rand = random.Random(0)
coeffs = [(rand.randrange(1, prime), rand.randrange(0, prime)) for _ in range(num_perm)]

def minhash(tokens):
    sig = []
    for a, b in coeffs:
        mini = prime
        for t in tokens:
            h = (a * (hash(t) & 0xffffffff) + b) % prime
            if h < mini:
                mini = h
        sig.append(mini)
    return tuple(sig)

sigs = [minhash(toks) for toks in rows]

# ── cluster by identical signatures (exact‑duplicate after tokenisation) ───
clusters = {}
for i, s in enumerate(sigs):
    clusters.setdefault(s, []).append(i)

orig = len(rows)
unique = len(clusters)
dedup_ratio = (orig - unique) / orig

# ── inline verification ─────────────────────────────────────────────────────
expected = 0.6  # rows 1‑3 cluster, rows 4‑5 cluster → keep 2 of 5
if abs(dedup_ratio - expected) < 1e-9:
    print(f"SUCCESS: dedup ratio {dedup_ratio}")
else:
    print(f"FAILURE: got {dedup_ratio}, expected {expected}")
    sys.exit(1)
