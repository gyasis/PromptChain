## Method (cited)  

The conversion will be performed by a **pure‑Python driver script** that invokes the **DuckDB** command‑line tool via the standard‑library `subprocess` module. DuckDB offers built‑in CSV auto‑type detection (`read_csv_auto`) and native Parquet output (`COPY … TO … (FORMAT PARQUET)`). By delegating the heavy lifting to DuckDB we keep the Python side limited to `subprocess`, `pathlib`, and `tempfile`, satisfying the “standard‑library‑only” requirement.

**Steps**

1. **Validate environment** – ensure the `duckdb` executable is on `PATH`.  
2. **Create a temporary DuckDB in‑memory database** – we will execute a short SQL script using `duckdb -unsigned -csv -batch`.  
3. **Read CSV with auto‑type inference**:  
   ```sql
   CREATE TABLE src AS SELECT * FROM read_csv_auto('path/to/input.csv');
   ```  
4. **Write the table as Parquet**:  
   ```sql
   COPY src TO 'path/to/output.parquet' (FORMAT PARQUET);
   ```  
5. **Exit** – the subprocess returns a zero exit code on success; errors are captured and re‑raised as Python exceptions.

All file‑system handling (creating output directories, cleaning up temporary files) is done with `pathlib`/`tempfile`. No third‑party Python packages are imported.

**Citation** – DuckDB documentation on CSV auto‐type detection and Parquet export:  

- DuckDB Docs – *Reading CSV files*: <https://duckdb.org/docs/sql/read_csv_auto>  
- DuckDB Docs – *Exporting Parquet*: <https://duckdb.org/docs/sql/copy#parquet>
