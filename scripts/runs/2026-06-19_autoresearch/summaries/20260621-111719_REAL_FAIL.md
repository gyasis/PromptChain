2. **Create sorted runs** – For each run, load the chunk into memory, sort it (`list.sort()`), and dump the sorted values to a temporary file. This implements the *run‑formation* phase of external merge sort.

3. **Multi‑way merge with distinct counting** – Open all run files as iterators and perform an n‑way merge using `heapq.merge`. While merging, keep the last emitted key; increment a counter only when the current key differs from the previous one. This yields an exact **count‑distinct** without ever materialising the full dataset.  
   - *Reference*: The corpus entry explains that sorting‑based distinct counting works by “identifying duplicate records after sorting and counting the remaining unique values”【corpus:memory_lane_v4】.

import heapq,sys
# simulated large input (line‑delimited values)
data='a b a c b'.split()          # distinct values: a,b,c → count=3
run_sz=2                           # size of each in‑memory “run”
runs=[sorted(data[i:i+run_sz]) for i in range(0,len(data),run_sz)]
cnt=prev=None
for v in heapq.merge(*runs):
    if v!=prev:
        cnt+=1
        prev=v
