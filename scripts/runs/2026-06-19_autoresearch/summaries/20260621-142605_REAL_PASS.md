## Method (cited)  

The solution follows the canonical “normalize → split → count → select‑top‑k” pipeline that is widely used in Python tutorials and StackOverflow answers [corpus]; [web:https://stackoverflow.com/questions/29539410/top-3-most-frequently-occurring-words-in-a-string-python].  

1. **Normalization** – Convert the input string to lower‑case and strip punctuation.  
   *Implementation*: `re.findall(r"\b\w+\b", text.lower())` extracts only word characters, discarding punctuation and whitespace in one pass.  

2. **Counting** – Feed the resulting list of words to `collections.Counter`.  
   *Rationale*: `Counter` is a hash‑based multiset that provides `most_common(n)` which returns the *n* most frequent elements already sorted by count (and then by first appearance for ties) [corpus].  

3. **Selection** – Call `most_common(3)` to obtain the top‑3 `(word, frequency)` pairs.  

4. **Output** – Print each pair on its own line in the format `word: count`.  

The entire algorithm is O(N) in the number of words, uses only the Python standard library, and requires no external dependencies.

```python
import re
from collections import Counter

def print_top_three(text: str) -> None:
    """Print the three most frequent words in *text* (case‑insensitive)."""
    # 1. Normalise & tokenise
    words = re.findall(r"\b\w+\b", text.lower())
    # 2. Count frequencies
    top_three = Counter(words).most_common(3)
    # 3. Print results
    for word, cnt in top_three:
        print(f"{word}: {cnt}")
```
