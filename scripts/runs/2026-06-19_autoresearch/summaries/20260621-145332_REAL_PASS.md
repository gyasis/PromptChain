**## Chosen Approach**  
The most effective strategy is to generate a synthetic teacher‑student dataset with an open‑source GPT‑OSS model served through Ollama, then distill that knowledge into a 1‑bit BitNet student using BitNet’s quantized training pipeline. First run the large GPT‑OSS model (e.g., the 120 B checkpoint) in Ollama to produce high‑quality responses for a diverse prompt set, as demonstrated in recent OSS distillation pipelines [web:https://huggingface.co/Jackrong/gpt-oss-120b-Distill-Llama3.1-8B-v2-GGUF]. Next, train a 1‑bit BitNet model (e.g., BitNet‑b1.58) on this data with the official BitNet training scripts, which provide optimized 1‑bit kernels for fast, loss‑aware distillation [web:https://github.com/microsoft/BitNet]. This combines proven teacher‑data generation with the most efficient 1‑bit inference framework, yielding a compact yet capable LLM for edge deployment.

## Plan

```
## Method (cited)

1. **Teacher‑data generation** –  
   - Serve the open‑source **GPT‑OSS‑120B** model through **Ollama** (see Ollama docs [1]) and generate synthetic responses for a curated prompt set (≈ 200 prompts covering arithmetic, commonsense, and code).  
   - Store each pair as `{ "prompt": “…”, "response": “…” }` in *teacher_data.jsonl*.  

2. **Student model selection** –  
   - Use **BitNet‑b1.58** (the 1‑bit LLM released by Microsoft [2]) as the student. The repository provides a **bitnet‑train.py** script that supports loss‑aware quantized training on CPU/GPU.

3. **Distillation pipeline** –  
   - Run the official BitNet training driver with the `--distill` flag, pointing it at *teacher_data.jsonl* and the pretrained 1‑bit checkpoint.  
   - Hyper‑parameters are kept lightweight for a quick proof‑of‑concept: `batch_size=8`, `epochs=1`, `lr=5e‑5`.  
   - The script writes *student_checkpoint.pt* and a small validation set *val_prompts.jsonl*.

4. **Verification** –  
   - Load the distilled 1‑bit model with the provided inference wrapper (`bitnet_infer.py`) and query a single prompt from the validation set.  
   - Compare the model’s answer to the teacher’s answer (exact match or tolerant string similarity).  

The entire workflow is orchestrated by **run_distillation.sh**, which is fully reproducible given Docker images for Ollama and BitNet (see Resources).
