## Method (cited)  

We implement a tiny command‑line utility **`csv_max_json.py`** that:

1. **Reads** a CSV string from **stdin** (or an optional file argument).  
2. Uses **`pandas.read_csv`** with a `StringIO` buffer so pandas can automatically infer numeric types, handle quoting, and treat empty fields as `NaN`.  
3. Calls **`df.max(skipna=True)`** to compute the per‑column maximums (numeric max for numbers; lexicographic max for strings).  
4. Serialises the resulting `Series` to **JSON** via `Series.to_json(orient="records")`, extracts the single object from the list, and prints a compact JSON map `{"col":max,…}`.  

The approach mirrors the widely‑cited StackOverflow solution *“How to find min/max values in columns of csv files into JSON like format in python”* [StackOverflow 37303643](https://stackoverflow.com/questions/37303643/how-to-find-min-max-values-in-columns-of-csv-files-into-json-like-format-in-pyth)).  

```python
#!/usr/bin/env python3
import sys, json
import pandas as pd
from io import StringIO

def csv_string_to_max_json(csv_text: str) -> str:
    """Parse CSV text, compute per‑column max, return JSON string."""
    df = pd.read_csv(StringIO(csv_text))
    max_series = df.max(skipna=True)
    # pandas to_json with orient='records' gives [{"col":max,...}]
    json_str = max_series.to_json(orient="records")
    obj = json.loads(json_str)[0]          # strip outer list
    return json.dumps(obj, separators=(",", ":"))

def main() -> None:
    # If a filename is supplied, read it; otherwise read from stdin.
    if len(sys.argv) > 1:
        csv_text = open(sys.argv[1], "r", encoding="utf-8").read()
    else:
        csv_text = sys.stdin.read()
    print(csv_string_to_max_json(csv_text))

if __name__ == "__main__":
    main()
```

The script is self‑contained, has no side‑effects beyond I/O, and prints a compact JSON object suitable for downstream piping.
