## Method (cited)

We will **prompt a cloud LLM** to perform few‑shot sentiment classification.  
The prompt supplies one positive (`great`) and one negative (`awful`) example, then asks the model to label the three target reviews (`great`, `awful`, `ok`).  
Few‑shot prompting is the standard, zero‑training way to obtain deterministic classifications from a pre‑trained LLM [web:https://leyaa.ai/codefly/learn/nlp/part-3/nlp-fewshot-learning-with-prompts/puzzle/15].  

Implementation details  

| Step | Action |
|------|--------|
| **1. Build prompt** | ```text\nReview: great → Sentiment: Positive\nReview: awful → Sentiment: Negative\nNow classify the following reviews, one per line, and output only the word *Positive* or *Negative* for each:\ngreat\nawful\nok\n``` |
| **2. Call LLM** | POST to the Ollama Cloud endpoint **https://ollama.com/v1/chat/completions** with JSON body `{model:"gpt-oss:120b", messages:[{role:"user",content:<prompt>}]}`. The request uses the bearer token stored in `OLLAMA_API_KEY`. |
| **3. Parse response** | The model returns a single string containing three words (one per line). The script strips whitespace and verifies each token is either `Positive` or `Negative`. |
| **4. Return result** | Print the three labels space‑separated (e.g., `Positive Negative Positive`). |

The entire workflow lives in **`label_reviews.py`**, a pure‑Python script that performs the steps above without any additional libraries beyond the Python standard library (`json`, `urllib.request`, `sys`).

```python
import os, json, sys, urllib.request
p="""Review: great → Sentiment: Positive
Review: awful → Sentiment: Negative
Classify each review below with only "Positive" or "Negative":
great
awful
ok"""
d=json.dumps({"model":"gpt-oss:120b","messages":[{"role":"user","content":p}]}).encode()
r=urllib.request.Request("https://ollama.com/v1/chat/completions",d,method="POST")
r.add_header("Content-Type","application/json")
k=os.getenv("OLLAMA_API_KEY")
if not k: sys.exit(1)
r.add_header("Authorization",f"Bearer {k}")
with urllib.request.urlopen(r) as f:
    c=json.load(f)
t=[w for w in c["choices"][0]["message"]["content"].split() if w in("Positive","Negative")]
if len(t)==3:
    print("SUCCESS:",*t)
else:
    print("FAILURE:",c)
    sys.exit(1)
